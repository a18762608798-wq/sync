# QuantumCircuit 基本属性

**日期**: 2026-08-03 16:51
**分类**: 编程/Python
**标签**: #qiskit #QuantumCircuit

## 背景

在构建变分演化电路时需要获取电路的基本信息，如量子比特数和经典比特数。

## 内容

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(4, 2)
print(qc.num_qubits)   # 4 — 量子比特数
print(qc.num_clbits)   # 2 — 经典比特数
print(qc.depth())      # 电路深度
print(qc.data)         # 电路中每条指令的列表
```

`qc.data` 返回列表，每项是可遍历的电路指令，`op.operation.name` 获取门名称。

## 要点

- `num_qubits` 和 `num_clbits` 是属性（不加括号），`depth()` 是方法
- `qc.data` 遍历每条电路指令，每个指令有 `.operation`（门对象）和 `.qubits` / `.clbits`
