# SparsePauliOp 创建与解析

**日期**: 2026-08-03 16:50
**分类**: 编程/Python
**标签**: #qiskit #SparsePauliOp #Pauli算符

## 背景

在 SSH model 的变分参数演化项目中，用 `SparsePauliOp` 表示 Pauli 算符构成的哈密顿量，需要创建 XX、ZZ 相互作用项并解析其结果。

## 内容

### 从稀疏列表创建

```python
from qiskit.quantum_info import SparsePauliOp

# 创建 qubit_num 量子比特系统上 (i, i+1) 的 XX 算符
xx = SparsePauliOp.from_sparse_list(
    [("XX", [i, i + 1], 1.0)],
    num_qubits=qubit_num,
)
```

`from_sparse_list` 参数格式：`[(Pauli标签, 作用位置列表, 系数), ...]`。

### 解析 to_list() 格式

`SparsePauliOp.to_list()` 返回 `[(label, coeff), ...]`，其中 `label` 是完整的 `num_qubits` 长度的 Pauli 字符串：

```python
H = get_ssh_H(4, 0.5, 0.5)
print(H.to_list())
# [('IIXX', 0.5), ('IIZZ', 0.25), ('XXII', 0.5), ('ZZII', 0.25), ('IXXI', 0.5), ('IZZI', 0.25)]
```

### Hermitian 判定

```python
assert H == H.transpose().conjugate()  # H.is_hermitian() 也可以用
```

### 算符简化

```python
ssh_op.simplify()  # 合并同类项
```

## 要点

- `from_sparse_list` 的 Pauli 标签只需写非 I 部分，Qiskit 自动补齐 I
- `to_list()` 返回的 label 是完整字符串（含所有 I），和 `from_sparse_list` 输入格式不对称
- 用 `H == H.transpose().conjugate()` 或内置 `H.is_hermitian()` 验证厄米性
