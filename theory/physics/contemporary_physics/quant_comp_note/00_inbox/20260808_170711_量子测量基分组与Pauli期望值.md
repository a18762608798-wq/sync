# 量子测量基分组与 Pauli 期望值计算

**日期**: 2026-08-08 17:07
**分类**: 理论/量子计算
**标签**: #量子测量 #Pauli #期望值 #对易分组 #qiskit

## 背景

在真机/模拟机上测量多算符的期望值，需要把观测算符按 qubit-wise 对易分组，每组用对应测量基，最后从计数直方图恢复每个 Pauli 的期望值。

## 内容

### 测量基分组与参数绑定

`get_commute_group(obs)` 用 `PauliList.group_commuting(qubit_wise=True)` 分组，每组生成一个测量基（各比特含 X/Y/Z 的并集）。`add_meas` 给电路加 `u(-θ,0,-φ)` 测量旋转门，`get_meas_params` 按 `PAULI_ROTATIONS` 把每个比特的测量基映射成 `(θ,φ)`：
```
X → (θ=π/2, φ=0)
Y → (θ=π/2, φ=π/2)
I/Z → (θ=0, φ=0)
```

### 从直方图恢复期望值

对每个 Pauli 生成掩码 `mask = pauli.x | pauli.z`（非 I 的位置为 1），对每个测量结果求奇偶性：
```python
parity = (mask & outcome).bit_count() % 2
value  = -1 if parity else 1
expects[pauli] = Σ frequency·value / shots
```
`<I> ≡ 1` 恒成立，可作 sanity check。

### 键类型必须统一（重要坑）

- `_get_pauli_list_expects` 返回的 dict 用 **Pauli 对象**作键。
- `get_op_val` 用 `pauli.to_label()`（字符串）查表 → 键类型不一致导致 `KeyError`。
- 修复：统一用 **Pauli 对象**作键（`Pauli` 可哈希、内容相等则 hash 相等，可从 `SparsePauliOp` 取出的 pauli 互查）。
- 或者统一用字符串 label。全链路必须一致。

### qiskit 系数是复数

`ob.coeffs` 是 `np.complex128`，所以 `coef * expval` 结果是复数标量（`np.complex128(...+0j)`）。若系数为实数，可取 `float(result.real)`。

## 要点

- qubit-wise 对易分组 + 每组独立测量基是测量多算符的标准做法。
- 期望值 = Σ (奇偶符号 × 频率) / shots，`<I>=1` 恒成立。
- dict 键类型（Pauli 对象 vs 字符串）必须全链路一致，否则 KeyError。
- SparsePauliOp 系数是复数，期望值计算结果是 complex128。
- `assign_parameters` 默认返回新电路、不就地修改，要捕获返回值。
