# SSH 模型 ZR 相边界计算方法

**日期**: 2026-07-28 00:00
**分类**: 理论/量子计算
**标签**: #SSH模型 #相图 #量子计算

## 背景

在 SSH 模型的变分参数演化项目中，需要计算 ZR order parameter 的相边界，以确定拓扑相变点。

## 内容

### ZR order parameter

对于 SSH 模型的基态 $|\psi_0\rangle$，通过以下步骤计算 ZR：

1. **偏迹截断**：对 8+ 比特系统，保留中间 4 个比特，去除边缘自由比特的简并影响
2. **计算反射算符期望值**：$Z_R = \text{tr}(\rho \cdot R) / \sqrt{(P_1 + P_2)/2}$
   - $R$ 是反射算符（由 SWAP 门构成）
   - $P_1, P_2$ 是两子系统的 purity

### 相边界搜索策略

1. **固定 δ=1**：求 $Z_R = 0$ 的 s 值，得到 s 方向的相变点 $s_p$
2. **以 $s_p$ 分段**：在 $s < s_p$ 和 $s > s_p$ 两个区间分别取若干 s 值
3. **固定 s**：对每个 s 求 $Z_R = 0.5$ 或 $Z_R = -0.5$ 的 δ 值，得到 δ 方向的相边界

### 分段原因

$s_p$ 是 $Z_R$ 在 δ=1 处的零点，也是 $Z_R$ 符号变化的分界点。两侧需要搜索不同的目标值（0.5 和 -0.5）。

## 要点

- ZR 作为 order parameter 在相变点处为 0
- 偏迹截断去除边缘自由度的影响
- 分段搜索是因为 ZR 的符号在 $s_p$ 处翻转
- 使用 `Roots.jl` 的 bracketing 方法需要确保函数在搜索区间内有符号变化
