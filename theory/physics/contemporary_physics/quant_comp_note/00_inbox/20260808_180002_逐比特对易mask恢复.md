# 逐比特对易分组与 mask 奇偶校验恢复

**日期**: 2026-08-08
**分类**: 理论/量子计算
**标签**: #measurement #pauli #commuting_group #qubitwise

## 背景

在实现 `qmeas.estimator` 的 Quark 路径时，需要将 Pauli 可观测量分组，对每组施加旋转门后在 Z 基测量，再从直方图恢复各 Pauli 的期望值。

## 内容

### 逐比特对易分组

利用 `PauliList.group_commuting(qubit_wise=True)` 自动分组。对每组计算测量基：

```python
basis_x = np.logical_or.reduce(group.x, axis=0)
basis_z = np.logical_or.reduce(group.z, axis=0)
measurement_basis = Pauli((basis_z, basis_x))
```

`measurement_basis` 的每个 qubit 位置：X/Z/Y/I → 需要 H/S†H/I 旋转到 Z 基。

### Mask 奇偶校验

从 Z 基测量直方图恢复 Pauli 期望值的核心方法：

```python
support = pauli.x | pauli.z
mask = sum(int(bit) << i for i, bit in enumerate(support))

for bitstring, count in hist.items():
    outcome = int(bitstring, 2)
    parity = (mask & outcome).bit_count() % 2
    sums[pauli] += count * (-1 if parity else 1)
```

原理：
- mask 标记了 Pauli 中非 I 的位置
- 在 Z 基测量中，bit=0 → 对应 Pauli 本征值 +1，bit=1 → 本征值 -1
- 奇偶校验直接给出该 Pauli 的本征值乘积：偶数个 1 → +1，奇数个 1 → -1
- 最终期望 = 加权平均

## 要点

- 逐比特对易组确定每个 qubit 的旋转（X→H, Y→S†H, Z→I）
- mask 编码了 Pauli 的非 I 支撑位
- `(mask & outcome).bit_count() % 2` 是核心：奇偶校验即本征值
- 此方法只适用于 qubit-wise commuting 组；纠缠对易组需要额外解 link 步骤（如 CNOT）
