# SSH 模型哈密顿量构造

**日期**: 2026-08-04 15:13
**分类**: 理论/量子计算
**标签**: #SSH模型 #SparsePauliOp #哈密顿量 #qiskit

## 背景

在 `04_project/variational_param_evolution/src/creato_op.py` 中用 Qiskit `SparsePauliOp` 构造 SSH 模型的哈密顿量，作为变分参数演化研究的物理模型。

## 内容

SSH 模型（Su-Schrieffer-Heeger）哈密顿量按 dimer（二聚化）链构造，相邻格点用 `link` 算符连接：

```python
XX(i) = SparsePauliOp.from_sparse_list([("XX", [i, i+1], 1.0)], num_qubits=n)
ZZ(i) = SparsePauliOp.from_sparse_list([("ZZ", [i, i+1], 1.0)], num_qubits=n)
link(i) = XX(i) + δ * ZZ(i)

J1 = 1 - s
J2 = s
H1 = Σ link(偶位置), H2 = Σ link(奇位置)
H = J1 * H1 + J2 * H2
```

- 参数 `s` 在两个子格之间插值：`s=0` 时只剩 `H1`，`s=1` 时只剩 `H2`，`δ` 控制 `ZZ` 耦合强度。
- Qiskit 的 `SparsePauliOp` label 约定：字符串最左字符对应 **qubit 0**，如 `"IIXX"` 表示 XX 作用在 qubit 2、3 上。
- `SparsePauliOp` 的标量乘、加法会自动合并同类项并 simplify（零系数项被丢弃，全零时保留首项为 0 系数），因此 `0 * op` 之类写法会得到系数为 0 的简并结果。

## 要点

- SSH 模型 = 二聚化最近邻 XX + δ·ZZ，`J1/J2` 由 `s` 线性插值决定。
- 4 qubit 时 `s=1` 使 `J1=0`，输出仅保留 `H2` 的贡献，哈密顿量大幅退化。
- Qiskit Pauli label 左起是 qubit 0，构造多体算符时注意对应关系。
