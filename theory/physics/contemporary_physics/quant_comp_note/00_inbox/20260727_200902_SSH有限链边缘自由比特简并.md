# SSH 模型有限链的边缘自由比特简并问题

**日期**: 2026-07-27 20:09
**分类**: 理论/量子计算
**标签**: #SSH #拓扑 #基态简并 #变分参数

## 背景

在 8 比特 SSH 模型链上计算零点关联（ZR_val）时，发现 s=1 的结果（-0.5）远偏离理论预期值 -1。分析发现这是由有限链边缘自由比特导致的基态简并问题。

## 内容

### SSH 模型耦合结构

SSH 模型具有交替耦合：$J_1 = 1-s$（链内），$J_2 = s$（链间）。

对于 8 比特链，当 s=1 时（$J_1=0, J_2=1$）：
- 有耦合的比特对：(2,3), (4,5), (6,7)
- **比特 1 和比特 8 是自由的**，即不与任何算符作用

### 基态简并

边缘自由比特导致基态 4 重简并：
- 比特 1 和 8 各自独立处于 |0⟩ 或 |1⟩，能量相同
- 稀疏特征值求解器会收敛到简并子空间中的某个具体态（通常是 |0⟩₁|0⟩₈）
- 不同简并态对反射算符的期望值不同，导致 ZR_val 偏离理论值

### 对比 s=0 的情况

s=0 时（$J_1=1, J_2=0$）：
- 有耦合的比特对：(1,2), (3,4), (5,6), (7,8)
- 没有自由比特，基态唯一确定
- ZR_val ≈ 1，符合预期

### 解决方案

添加边缘微扰解除简并：

```julia
function get_ssh_group_state(qubit_num::Int, s::Real, δ::Real; ϵ::Real=0.0)
    H = get_ssh_H(qubit_num, s, δ)
    if ϵ ≠ 0.0
        Z = sigmaz()
        qubit_dims = ntuple(_ -> 2, qubit_num)
        H += ϵ * multisite_operator(Val(qubit_num), 1 => Z)
        H += ϵ * multisite_operator(Val(qubit_num), qubit_num => Z)
    end
    energy0, ψ0, _ = eigenstates(H; sparse=true, eigvals=1, sortby=real, rev=false)
    return real(energy0), ψ0
end
```

取 $\epsilon \approx 0.01$ 即可在不显著改变态结构的前提下破坏简并。

## 要点

- SSH 模型有限链在 s=1 时边缘比特自由，导致基态简并
- 简并度 = $2^{\text{自由比特数}}$
- 稀疏求解器在简并子空间中收敛到不定态，ZR_val 不可预测
- 加小边缘 Z 场 (ϵ ≈ 0.01) 可解除简并，得到有确定 ZR_val 的基态
- s=0 和 s=1 在有限链上的行为不对称：前者无简并，后者有
