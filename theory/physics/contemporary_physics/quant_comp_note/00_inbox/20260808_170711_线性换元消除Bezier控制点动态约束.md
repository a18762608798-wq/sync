# 线性换元消除 Bezier 控制点的动态约束

**日期**: 2026-08-08 17:07
**分类**: 理论/量子计算
**标签**: #变分算法 #参数化 #约束优化 #线性换元 #Bezier

## 背景

变分参数优化中，Bezier 控制点 `(s_p, δ_p)` 必须落在起点 `(s_0, δ_0)` 与终点 `(s_1, δ_1)` 之间。原实现用 4 条动态不等式约束，且 `pidx=-1` 时 `s_0 > s_1` 导致 `min/max` 麻烦、SLSQP 失败。

## 内容

### 原始问题

控制点约束为：
```
s_p ∈ [min(s_0,s_1), max(s_0,s_1)]
δ_p ∈ [min(δ_0,δ_1), max(δ_0,δ_1)]
```
原实现写成了依赖另一个优化变量 `v_0` 的动态约束（`s_0 = get_branch_start(phase_idx, v_0)`），既复杂又脆弱。

### 线性换元

定义两个 `[0,1]` 自由参数 `(u_s, u_δ)`：
```
s_p = s_0 + u_s · (s_1 - s_0)
δ_p = δ_0 + u_δ · (δ_1 - δ_0)
```
- `u_s, u_δ ∈ [0,1]` 自动保证 `s_p` 落在 `[min(s_0,s_1), max(s_0,s_1)]`，即使 `s_0 > s_1` 也成立，**无需 min/max**。
- 四条动态约束全部删除，只剩对每个变量的 box 约束。
- `u_s = u_δ = 0.5` 即区间中点，初始值直观。

### 代价

优化后的 `result.x[1]`、`result.x[2]` 是 `(u_s, u_δ)` 而非 `(s_p, δ_p)`。若要输出真实控制点需逆变换（代码里传给演化路径的仍是真实 `(s_p, δ_p)`，物理代码不用改）。

### 代码变化

- `objective` 内：`x[0:3]` 从 `(v0, sp, δp)` 改为 `(v0, us, uδ)`，再做 `sp = s0 + us*(s1-s0)`。
- `optimize_branch`：删除 4 条动态约束，`constraints = []`；`lb/ub` 前三个变量保持 `[0,1]`；`x0` 简化为 `[0.5,0.5,0.5]`。

## 要点

- 用 `[0,1]` 自由参数做线性插值，可把"控制点在端点间"的区间约束转化为无约束的 box 约束。
- 消除依赖其他变量的动态约束，简化实现、避免 `pidx=-1` 不可行问题。
- 语义代价：优化变量与物理变量不同，需逆变换。
- 属于"重新参数化（reparameterization）"思路：让不可行域在参数空间中消失，而非用约束排除。
