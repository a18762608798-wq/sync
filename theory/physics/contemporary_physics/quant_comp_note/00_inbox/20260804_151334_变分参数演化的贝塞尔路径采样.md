# 变分参数演化的贝塞尔路径采样

**日期**: 2026-08-04 15:13
**分类**: 理论/量子计算
**标签**: #变分参数 #贝塞尔曲线 #参数演化 #get_evolution_path

## 背景

在 `04_project/variational_param_evolution/variational_fidelity/get_evolution_path.py` 中，用二次贝塞尔曲线在变分参数空间 `(s, δ)` 上定义一条连续演化路径，再按时间分段离散采样，用于计算路径上的 fidelity。

## 内容

二次贝塞尔曲线由起点 `P0`、终点 `P1`、控制点 `Pc` 定义，参数 `tr ∈ [0,1]` 处取值为：

```python
B(tr) = (1 - tr) ** 2 * P0 + 2 * tr * (1 - tr) * Pc + tr ** 2 * P1
```

路径采样逻辑：

```python
T = sum(Δts)
t = 0
for Δt, dp in zip(Δts, decompose_points):
    t += Δt * dp
    tr = t / T
    s = bezier(s0, s1, sc, tr)
    δ = bezier(δ0, δ1, δc, tr)
    path.append((s, δ))
    t += Δt * (1 - dp)
```

- `Δts` 把总时间 `T` 分成若干段，`decompose_point ∈ [0,1]` 指定每个段内的采样时刻（段内比例）。
- `tr = t / T` 是全局归一化时间，`s` 和 `δ` 共享同一 `tr`，因此路径是 `(s, δ)` 平面内的一条二维二次贝塞尔曲线。

边界与健壮性要点：

- 最后采样点的参数为 `tr = 1 - Δt_last·(1 - dp_last)/T`，只有最后一个 `decompose_point == 1` 时才恰好落在终点 `end`，否则路径不包含终点。
- 需校验 `T > 0`（所有 `Δt > 0`）避免除零，并校验 `decompose_point ∈ [0,1]`。

## 要点

- 二次贝塞尔曲线是二维参数空间中连接起止点、受控制点牵引的常用光滑路径。
- 全局时间参数化下，采样点不一定包含终点，需按需补点。
- 对 `Δts`、`decompose_points` 做断言校验可同时消除除零与越界风险。
