# 绝热演化简并初态

## 对称性保护

**为什么打开简并**：在非简并处（如 $s=0$）基态有确定的对称性；演化起点保持这种对称性，绝热演化过程中对称性守恒，可禁止简并能级间的跃迁，从而保护演化路径.

以SSH模型为例, **逻辑链**：

1. 找全局守恒量：$U_x = \bigotimes_i X_i$, $U_z = \bigotimes_i Z_i$，满足 $[U_i, H(t)] = 0$，且 $[U_i, U_j] = 0$. 其中 $U_y$ 冗余，因为 $(-i)^N U_y = U_x U_z$.
2. 构造 $P = U_x + 2U_z$，本征值 $\{3, -1, 1, -3\}$，足以标记四个简并态.
3. 加约束 $H_c = H - \epsilon P$，简并能级分裂，目标基态（$\langle P \rangle = 3$，能量 $-3\epsilon$）被隔离出来.
4. 该对称性在整个演化中守恒 → 禁止简并能级间跃迁.

## 观察劈列

**$\epsilon$ 取值经验**：

- 观察谱分裂、保持能级排列顺序时：取小量（目前 0.05），过大可能让同对称性的能级直接跑到最下面，破坏初始能级排列顺序.
- 只关注最低态时：取大一些也无妨（ZR 计算中用 0.5）.
