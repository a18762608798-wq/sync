# data spec

## 可利用的库

`qmeas` 库中有对于 ssh 初始态(注意边界需要True)和哈密顿量.

## 真机比特

* 线（8 比特，开链实验）：Baihua `[67, 68, 69, 70, 71, 72, 73, 74]`, 作为一般的选择.
* 环（10 比特，周期边界实验）：Baihua `[125, 126, 127, 128, 129, 142, 141, 140, 139, 138]`。
* 环砍成 8 链时按子链分选：环最佳 8 子链 `[126, 127, 128, 129, 142, 141, 140, 139]`. 用作拓扑相初态, 以满足 1-8 的link.

逻辑比特按链顺序映射到上述物理比特(拓扑相初态主要放在最佳8子链, 其余两个比特作为1-8的link中间比特), **qiskit 转译时传 `coupling_map` 把拓扑 pin 死（线为线性、环为 10 环闭合）并给定 `initial_layout`，`optimization_level=3`**.

## 数据保存

完整保留中间计算结果数据, 以供后续调用和检查.

子实验有很多图像不会在正式论文中展示, 但是依然需要作为阶段性结果绘制.
