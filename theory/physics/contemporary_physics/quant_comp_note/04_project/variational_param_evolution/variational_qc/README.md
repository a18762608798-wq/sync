# README

这里主要讨论具体变分使用电路和拓扑分类策略

## 变分参数演化电路

qiskit的 `QAOAAnsatz` 和绝热演化联系不是很直接，更应该当作一个启发式的一般性的变分算法。

1. `QAOAAnsatz` 本质上只支持演化一次, 也就是H只有H(0)和H(end)两个数值.
2. H分解后的时间没有绑定; 当然我们可以手动设置这个绑定效果, 也可以不绑定追求更高的表达能力.

但是无论如何，核心问题在于：**演化路径没有被天然支持.**

我们决定直接用 `PauliEvolutionGate`, 手动**将演化路径**和**演化步长**(在量子计算机上再启用**步数**, **分解阶数**)作为变分参量，并绑定H各项演化步长.

## 变分策略

### Cost function

对于任意一个目标 $H_c(s, \delta)$ 的基态，有:

$$
\min H_c
$$

此时求出的态理论上就是目标态.

### 分类策略

从相1, 2, 3的所有可制备出发点到目标位置，记录cost function的优化结果.

对于平均结果最好的一个相认为和目标位置在同一个相.
