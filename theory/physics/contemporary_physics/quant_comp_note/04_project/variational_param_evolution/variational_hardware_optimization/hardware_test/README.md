# README

## 验证方向

本批测试用于评估真机(Quark)在多大程度上可信。总体结论较为悲观：真机噪声使测量能量系统性偏离模拟机, 且电路越深偏差越大, 真机结果只能作为趋势/量级参考。

1. 用 Bell state 筛选真机上的环形电路双比特门保真度分布见 `data/bell_compare.json`, 以此选出保真度相对较高的链路。
2. 验证三种初态在筛选链路上的真机可信度.
3. 给定一个优化 path 之后, 对比模拟机与真机结果.

### 演化电路测试 (evolution_test.py)

`run_evolution_test(end, pidx=1, step=1, order=1)` 完整流程：

1. 模拟机(DIRECT_L)求最优参数组, 作为 SPSA 初值；
2. 模拟机(SPSA)精细优化得到 `aer_res`；
3. 用最优参数复现电路, 在真机(Quark/Baihua)上求期望值 `evs`。

脚本对三组 `(step, order)` 组合各跑一遍, 结果存于 `data/evolution_test_results.json`：

| 组合 | end | aer (模拟) | quark (真机) | 偏差 |
| ------ | ----- | ----------- | ------------- | ------ |
| step=1, order=1 | [0.1, 0.9] | -9.840 | -6.386 | +3.45 |
| step=1, order=2 | [0.1, 0.9] | -9.850 | -5.584 | +4.27 |
| step=2, order=1 | [0.1, 0.9] | -9.856 | -5.154 | +4.70 |

## 总结

- 真机能量**始终显著高于**模拟机, 无法达到模拟机的能量下界; 说明真机噪声/误差导致优化目标无法兑现.
- 电路越深(`step` 更大), 偏差越大: step=1,order=1 偏差 +3.45, step=2,order=1 偏差 +4.70.
- 更值得注意的是: **同样 `step=1` 下提高 order(order=2)偏差反而更大**(+4.27 vs +3.45). 说明高阶 Suzuki-Trotter 在真机上因门数增多而损失更大, 算法精度提升被硬件噪声抵消——**对真机而言, 更精确的分解并不占优**.
- 结合初态测试 (真机能量同样系统性偏低约 3~4), 可认为**真机结果只能作为量级参考, 不能用来比较不同参数组的优劣**——模拟机上获得的"最优参数"在真机上并不一定最优.
- 因此后续以真机为目标做优化时, 应预期噪声主导, 悲观看待: 不仅电路深度, 连分解阶数、门数增加都会让偏差扩大, 仅将真机结果作为趋势参考.
