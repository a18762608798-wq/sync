# README

> 本目录属于 `variational_optimization/` 系列实验，编号 **02**。

## 项目概览

**02 · 真机适配与硬件优化**: 在 01 暴露 quark 真机噪声问题之后，针对真机现实约束重新设计变分方案——环形电路、直线轨迹、参数解耦，目标是用穷极计算力算出 quark 真机能给的最低能量.

主要内容:

* **环形电路**: 解决 `pidx = -1` 时线性电路交换门过多的问题.
* **直线轨迹**: 真机最多只能跑 2 个时间点，改用直线轨迹；参数编码为离散 `(step, pidx, order)` + 连续 `(p0, x_i, Δt_i)`，全部换元到 $[0,1]$.
* **目标函数**: 模拟机与 quark 真机统一使用普通 `objective`（曾尝试对输入参数注入随机噪声的 `robust_objective`，实验无效果，已移除）.
* **优化算法**: 模拟机 `DIRECT_L`（全局）+ `SPSA`（局部）；真机 `SPSA`.
* **硬件可信度测试**（`hardware_test/`）: Bell 态筛选双比特门 → 三种初态测试 → 演化电路测试，结论是真机结果只能作趋势参考.
* **产物**: `data/` 下 `ideal_spectrum.npz`（理想谱）、`direct_dic.json`（DIRECT_L）、`aer_dic.json`（模拟机 SPSA）、`quark_dic.json`（真机）.

## 方案改进

### 环形电路

对于 pidx = -1 情况线性电路会引入大量不必要交换门。采用环形减少交换门.

### 参数设置改进

我们发现在实际的量子硬件上压根不能采用超过2次时间点的演化路线。此时复杂的演化轨迹毫无意义, 采用直线即可. 参数编码如下:

#### 离散参数

(step, pidx, order)

#### 连续参数

##### 初始参数

* 演化起点 $p0$
* 分解位置 $x_i$ (而非时间点)
* 时间步长（换元后的 $\Delta t_i$）

其中

$$
\begin{cases}
0 \le p0 \le 1\\
0 \le x_1 \le x_2 \le ... \le 1\\
0.01 \tau \le \Delta t_i \le \tau
\end{cases}
$$

**默认 $\tau = 20$**.

##### 去约束

稍加换元可以将参数范围限定在 $[0, 1]$:

$$
\begin{split}
&x_i = 1 - \prod_{j=1}^i (1 - {u_x}_j) \rightarrow\\
&{u_x}_i = \frac{x_i - x_{i-1}}{1 - x_{i - 1}}, \quad x_0 = 0
\end{split}
$$

此时若 ${u_x}_i \in [0, 1]$, 必然有 $x_i \ge x_{i - 1}$;

同理对于 $\Delta t_i$ 有:

$$
\Delta t_i = \tau * (0.01 + 0.99 * u_{\Delta})
$$

where $u_\Delta \in [0, 1]$, 综上:

$$
u_{p_0}, {u_x}_i, u_\Delta \in [0, 1]
$$

此外轨迹取直线则有参数方程:

$$
\begin{split}
s_i = s_0 + a {u_x}_i\\
δ_i = δ_0 + b {u_x}_i
\end{split}
$$

where:

$$
(a, b) = (s_1 - s_0, δ_1 - δ_0)
$$

##### 去边界

如果需要SPSA算法，边界也可以去除:

$$
u = \frac{1}{1 + e^{-t}} \quad t\in [-\infin, +\infin]
$$

### 优化算法

#### 优化目标

* 对于模拟机的优化对于输入参数增加随机噪声.
* 对于quark保留原本的cost function.

#### 优化算法

对于模拟机:

* 全局优化: DIRECT_L
* 局部优化: SPSA

对于量子计算机：

* SPSA

### 计算范围

穷极计算力计算一个点即可，暂以 $s=0.5, δ=0.3$ 为例. 计算quark可以给到的最低值.

### debug

quark 对于角度接近0的rzz会直接删除。需要设置边界.

* s = 0 && 1, δ = 0 的同时 u_x = 0 && 1
* Δt = 0

这会令quark优化更趋向于压根不加任何门, 暂时令:

$$
\begin{cases}
0.95 \ge s \ge 0.05
0.95 \ge \delta \ge 0.05
Δt \ge 0.05 \tau
\end{cases}
$$

## 问题与下一步改进

这说明两个问题:

1. 不必执着于绝热烟花; 在有噪声的量子计算机上，噪声问题相对于原理问题永远是主要矛盾;
尝试一般的、更浅的变分电路(**我觉得可以cnot link 所有的就可以，完全不需要演化**).

2. 如若专注分类，尽量让三相深度相同，有利于分类; 如若执着于制备态，越浅层电路越好.
