# README

这里主要讨论具体变分使用电路和拓扑分类策略

## 背景与基本立场

### 机器学习路线问题

1. 首先对于判断模拟机和量子计算机上的态是否相同不需要测量保真度，事实上只需要该态在哈密顿量加上对称性惩罚项($H_c$)的期望取最小即可. 本质上是在声明：能量和对称性都满足要求的态是目标态.
2. 其次如果只在(s=0, δ=1)以及(s=1, δ=1)和(s=0.5, δ=0)三个点附近计算ZR后学习，事实上没有获得任何中间信息，没有什么能学习的.
3. 再然后想到使用整个相图的离散点 ZR 计算结果做机器学习. 但这本质上和量子机器学习无关, 只是对结果的后处理，本质上是经典数据拟合. 而且如果我们有直接计算相图中任意一个离散点ZR的能力为什么不直接去算呢？为什么还需要学习？
4. 由于量子计算机误差，直接测量的ZR可信度十分低，应该对测量结果分类而不必太在乎具体的数值。**此时classical shadow的纠错方法收益有限**, 因为该方法不怎么改变测量结果的相对大小. 若后续需要精确估计更多算符期望，classical shadow 仍有其价值.

### 新思路

我们的核心问题有二：

1. 如何最优的制备相图中任意一点 $H(s, δ)$ 的满足对称性 $P=3$ 的基态，并估计制备效果？
2. 如何测量改态的ZR值？

事实上这两个问题有重叠。很容易想到, **当演化初态和目标态是同一个相的时候，制备效果理应更优**.

因此我们对**三种离散的演化起点**（对应三个相分区的初始态）分别优化演化路径，比较各起点的结果，取效果最好起点组作为同相判定。这和 `../variational_feasibility/` 中的实现一致：内层对三种起始分支 `pidx ∈ {1, 0, -1}` 分别调用底层优化，取 cost 最小的分支作为该目标点的最优解。

当然，如果我们可以忍受指数次测量，也可以直接用上面所有线路的最优解作为计算ZR的态. 此时不必在乎 $ZR$ 到底是不是严格接近 $±1$, 因为我们已经没有更优的线路了. 因此只要可以把不同目标点的ZR结果分类成三种就可以了.

**我们也可以将二者结合**, 将起点ZR和目标点ZR的距离作为惩罚项，做整体优化。

## 变分策略

### Cost function

对于任意一个目标 $H_c(s, \delta)$ 的基态，优化目标:

$$
\min H_c
$$
其中cost function是：

$$
\begin{split}
H_c &= (1-s) \sum_{i\text{ odd}} (X_i X_{i+1} + \delta Z_i Z_{i+1}) + s \sum_{j\text{ even}} (X_j X_{j+1} + \delta Z_j Z_{j+1}) \\
&- ϵ_1(\prod_{i=1}^{N} X_i + 2\prod_{i=1}^{N}Z_i)
\end{split}
$$

**这里的 $\epsilon_1$ 就不必写小量了**，因为我们只挑最低能量。具体多大取决于我们更看中对称性还是能量. 实际实验（见 `../variational_feasibility/`）中暂取 $ϵ_1 = 1$，仅优化能量加对称性惩罚项。

若后续要利用相信息，可再加入惩罚项做整体优化:

$$
+ \epsilon_2|zr - ZR_{p}|^2
+ \frac{ϵ_3}{τ} * T
$$

$\epsilon_2$ 项为zr与起点相 $ZR_p$ 的距离的惩罚项，zr为终点态的ZR期望, $ZR_P$ 的数值取决于当前起点，理论值为 $0, -1, 1$, 实际可以取每个相起点ZR期望的均值. $\epsilon_3$ 的大小取决于对ZR测量结果的相信程度.

$\epsilon_3$ 项作为对演化时间的限制，倾向于在优化结果相差不大的时候演化更短的总时间，和经典演化时间(需模拟机计算)成反比. 不过我想量子计算机的误差从某种程度上会自动给我们加这一项.

**对于所有的相起点迭代, 对变分参数优化.**

### 变分参数

#### 演化路线

这是核心问题：对于一个二维相图，演化路线如何设计？涉及到的变分参数有哪些？

**演化起点（离散分支）**：三种离散起点由 `pidx ∈ {1, 0, -1}` 选定（对应三个相分区），内层用一个自由参数 $v_0 \in [0, 1]$ 表示起点中非固定的分量:

$$
\begin{cases}
pidx = 1: & s_0 = 0,\; δ_0 = v_0\\
pidx = 0: & s_0 = v_0,\; δ_0 = 0\\
pidx = -1: & s_0 = 1,\; δ_0 = v_0
\end{cases}
$$

注意这里的出发点本质上是第一个时刻的演化出口. 由于能隙最优路线不一定是直线路径，甚至对于复杂的相不一定始终在靠近.

但是我们其实知道我们的相没那么复杂, 而且如果所有自由度都放开优化难度实在太大，所以作出**第一个限定假设：最优演化路线中始终靠近目标点**.

此时演化路径一定是一个**没有拐点**的曲线（即曲率不变号）, 参考 [bezider曲线](../concept/bezier_curve.md), 构建(s0, δ0)到(s1, δ1)的演化曲线:

$$
\begin{split}
&\mathbf{s}(t') = (1-t')^2\mathbf{s}_0 + 2t'(1-t')\mathbf{s}_p + t'^2\mathbf{s}_1,\\
&\mathbf{\delta}(t') = (1-t')^2\mathbf{\delta}_0 + 2t'(1-t')\mathbf{\delta}_p + t'^2\mathbf{\delta}_1,\\
&where \quad t'\in[0,1]
\end{split}
$$

where

$$
t' = \frac{t}{T}
$$

控制点 $s_p, \delta_p$ 应落在两端点之间. 为避免 `pidx=-1` 时 $s_0>s_1$ 导致的 `min/max` 动态约束不可行，实际实现（见 `../variational_feasibility/`）将控制点换元为两个 $[0,1]$ 自由参数 $(u_s, u_\delta)$:

$$
\boxed{
\begin{aligned}
s_p &= s_0 + u_s\,(s_1 - s_0)\\
δ_p &= δ_0 + u_\delta\,(δ_1 - δ_0)
\end{aligned}}
\qquad
u_s, u_\delta \in [0, 1]
$$

$u_s = u_\delta = 0.5$ 即区间中点，初始值可直接取 $0.5$.

#### 变步长

时间步长和步数本身可以作为参数

$$
\begin{split}
&\sum_{i} Δt_i = T \\
&t_i = \sum_{j = 1}^{i - 1} Δt_j + \frac{Δ t_i}{2}
\end{split}
$$

对于 $\frac{dt_i}{T} ≈ 0$ 时，直接去掉这一步的演化门(这里由于量子计算机误差可能会导致贫瘠高原问题，应该需要改进成离散变量优化). 实际中每个 $Δt_n$ 限制在 $(10^{-3}τ, τ)$ 内，$τ=10$（trotter分解误差一定抵消绝热优势影响点）.

#### 分解时间点

每个 trotter 步的分解时间点 $d_n$（相对当前步长的百分比）本身也是变分参数, $d_n \in [0, 1]$, 用于均衡绝热演化的长时间优势和 trotter 分解误差.

#### 其他

1. T 本身也可以作为变量，不必约束它. 换言之 $Δ t$ 的和不必有限制.
2. Trotter decompositon 阶数也可以作为变分参数, 视效果而定.

## 变分参数演化电路

qiskit的 `QAOAAnsatz` 和绝热演化联系不是很直接，更应该当作一个启发式的一般性的变分算法。

1. `QAOAAnsatz` 本质上只支持演化一次, 也就是H只有H(0)和H(end)两个数值.
2. H分解后的时间没有绑定; 当然我们可以手动设置这个绑定效果, 也可以不绑定追求更高的表达能力.

但是无论如何，核心问题在于：**演化路径没有被天然支持.**

我们决定直接用 `PauliEvolutionGate`, 手动**将演化路径**和**演化步长**(在量子计算机上再启用**步数**, **分解阶数**)作为变分参量，并绑定H各项演化步长.

优化按三层层次进行（与 `../variational_feasibility/` 一致）:

* **外层**（`outer_optimize`）: 对每个 trotter 分解阶数 `order`，迭代步数上限 `step`，调用内层取全局最优.
* **内层**（`inner_optimize`）: 对三种离散起始边界 `pidx ∈ {1, 0, -1}` 分别调用底层优化，取 cost 最小的分支.
* **底层**（`optimize_branch`）: 固定 `pidx`, `step`, `order`，优化连续变分参数（演化起点 $v_0$、Bezier 控制参数 $(u_s, u_\delta)$、时间步长 $Δt_n$、分解时间点 $d_n$）.

## 方法优势

1. 仅在 ZR 三分类的意义下，纠错不是必须的; 若需要精确估计算符期望值，仍可引入经典shadow等纠错方案.
2. 改方法如果不使用 $ϵ_3$ 项有很强的扩展性。由于增加比特数并不直接增加电路深度, 同时H_c测量settings数量恒为2，理论上可以完全发挥量子计算机优势.
