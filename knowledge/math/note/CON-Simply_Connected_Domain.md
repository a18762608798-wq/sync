# Simply Connected Domain [AI]

**DEFINITION:**

设 $D \subset \mathbb{C}$ 为复平面上的区域（非空开连通集）. 若在 $D$ 内任取一条不自交的简单闭合曲线 $\gamma$，$\gamma$ 所围内部区域的所有点也都属于 $D$（等价地，$D$ 内任意简单闭合曲线都可以在 $D$ 内连续收缩为一点），则称区域 $D$ 是**单连通**（simply connected）的.

**EXAMPLE:**

- 单连通区域：整个复平面 $\mathbb{C}$、实心圆盘 $D_1 = \{ z \in \mathbb{C} \mid |z| < 2 \}$.
- 非单连通（多连通）区域：挖去原点的复平面 $\mathbb{C} \setminus \{0\}$、圆环 $D_2 = \{ z \in \mathbb{C} \mid 1 < |z| < 2 \}$（曲线 $|z| = 1.5$ 位于 $D_2$ 内，但其围住的内部点 $|z| \le 1$ 不属于 $D_2$）.

**NOTE:**

**区域、函数与路径三者的独立性**：

1. **单连通**仅形容**点集区域 $D$** 的几何拓扑形状（区域内部有没有“洞”），与被积函数 $f(z)$ 是否解析无关，也与具体积分路径 $\Gamma$ 是否自交无关.
2. **解析**仅形容**被积函数 $f(z)$** 的可微性质（函数有没有奇点/坏点）.
3. **闭合 / 自交**仅形容**积分路径 $\Gamma$** 的几何走法.
