# Zotero Highlighter（Zotero PDF 精炼划重点与框选规范）

本 skill 专用于在 Zotero 的 PDF 附件上打出**沿理论推导脉络全覆盖、高信息密度、带标准中文译名与 Unicode 纯文本公式**的学术标注，杜绝“机翻摘要式 / 报幕句式”的低质划线，以及“只标结论、丢掉推导”的断链标注。

## 1. 核心原则（为什么这样标）

低质插件式标注的通病是：只挑好匹配的纯文本报幕句（如 *"The value of X is of central importance"*）或半截名词（如 *"known as Y"*），漏掉真正的数学定义式与物理机制，再把场外剧透塞进批注。
高质量标注必须满足**就地自洽**：
1. **看高亮原文**就能读出完整的定义条件、物理因果或定量判据；
2. **看框选区域**就能直接看到核心公式组、能量曲线或总结图表；
3. **看批注（Comment）**就能获得「标准中文译名 + 核心公式（Unicode 纯文本） + 隐含假设/物理实质」。
4. **按页码顺序只读高亮+批注就能复述整节推导脉络**（假设→模型→关键推导步→近似→结果→验证），不必翻书——这是检验是否标全的唯一标准。

## 2. 选句与框选铁律

### 2.1 三不标（严禁插件式报幕）
1. **不标修辞性报幕句/过渡句**：严禁标 *"X is very important"*、*"We now consider Y"*、*"It is convenient to introduce Z"* 等无实质结论的句子。
2. **不标孤立的半截短语**：严禁只划 `"known as the Lennard-Jones potential"` 或 `"in the [100] direction"` 这种离开上下文无法独立成义的残片。
3. **不脱离被标句做跨页剧透**：批注必须紧扣当前被标句子或公式本身的物理涵义与成立条件，禁止在第一章导言句里把后面五页的公式全塞进去。

### 2.2 三必标（文字高亮 + 区域框选并用）
1. **必标完整命题句（`text=` 模式）**：主谓宾齐全，自带定义条件、物理机制或对称性判据的完整句子；**推导链上的假设句、近似声明句（如“只保留最近邻”“忽略动能”“长波近似”）同样必标**，结论的依据在批注里一句话交代出处即可。
2. **只标结论，不标过程**：定义式、结果式、稳定性判据、机制 verdict、验证性算例必标；推导中间步（变换、消参、量级估计、次级例证）一律不标。跳步存疑处打红 `[Q]` 而不是跳过。
3. **必标关键图表与总结表（`rect=` 模式）**：当一节的核心定量结果汇总在某张图或表（如离子晶体能量分解图、各晶向声速/有效弹性常数对照图、相图）时，必须先调用 `zotero_get_page_layout(attachment_key, page)` 获取检测框 `bbox`，再用 `zotero_create_annotation(..., rect=bbox)` 框选该图表；**推导的核心公式组（如 Hamilton 量对角化、弹性矩阵）同样值得一个 `rect`**，不要只框图不框公式。
4. **必补核心公式（Unicode 纯文本）**：PDF 文本层中的上下标、希腊字母常有缺失或乱码。无论高亮的是公式引出句还是 `rect` 框选，**批注中必须用普通 Unicode 纯文本写出该处的精确公式**：希腊字母直接写（α β σ ε ρ λ δ），上下标用 Unicode 上下标字符（R₀ σ⁶ C₁₁ √ ∑ ∂ → ≈ −·），没有对应字符时用 ASCII 写法（如 U_tot、dU/dR、e_ij），**禁止用 `$LaTeX$`**。
5. **必标公式编号（`text=` 高亮编号本身）**：编号是公式的地址，直接高亮编号字符串（如 `"(11)"`），颜色按公式性质（定义蓝 `[定]` / 推导绿 `[性]`），comment 写 `[式 Eq.(N)]=…公式内容 Unicode…`，tag 追加 `式`。编号锚定的是公式本体行的那一处；若 `text=` 报多处匹配，才加长上下文至含编号的半句。

### 2.3 颗粒度控制（结论模式）
- 默认采用**结论模式**：只标结论性公式与核心观点——定义式、结果式、判据、机制 verdict、验证性算例/图表；推导中间步、次级例证、重复表述一律不标，**不生成 Zotero 子笔记（Child Note）**，不打零碎的生词灰色下划线。
- 量级指引：一章 **25～35 条**，宁缺毋滥——拿不准要不要标的，一律不标。
- 收工检查：遮住书，只读本节标注，能否复述出“结论是什么、凭什么成立（依据一句话）、在哪被验证”。

## 3. 配色与标签体系（与 Zotero 根规范 `3QRJF6GA` 严格同步）

开工前可调用 `zotero_get_notes(query='PDF标记规范')` 核对根规范。读前先确定使用**教材套**还是**论文套**，绝不混用。

**公式 tag `式`（可叠加，不占前缀位）**：凡批注含核心方程/关系式（能量式、定义式、平衡条件、对称关系、色散关系……），在原前缀 tag 之外追加 `式` tag（如 `["性","式"]`），方便按 tag 一次筛出全章公式；纯数字、百分比、单位换算不算式，不加。

### 3.1 教材套（Textbook Set，默认用于物理/数学教材）

## 4. 批注（Comment）黄金格式

每条标注的 `comment` 必须遵循以下三段式结构，简洁锐利，直奔主题：

```text
[<前缀>] <英文专有词>=<国内标准中文译名>：<一句话物理实质或隐含假设> | <核心公式 Unicode 纯文本>
- 推导步（`[性]`）批注多写半句承接关系：上游用哪个假设/结论 → 本步得到什么 → 供下游哪里用，保证链条可追溯。
```

### 4.1 英文专有名词查译铁律
- 凡首次出现的英文专有术语，**必须先核对国内标准学术译名**（例如固体物理遵循黄昆/谢希德《固体物理学》及全国科学技术名词审定委员会译名：*cohesive energy*=内聚能/结合能，*lattice energy*=晶格能，*van der Waals-London interaction*=范德瓦耳斯-伦敦相互作用，*Madelung constant*=马德隆常数，*dilation*=体胀，*elastic compliance/stiffness constants*=弹性顺度/劲度常数，*bulk modulus*=体弹性模量），并在批注开头显式写出 `英文=中文`。

### 4.2 正反对比示例

- **差批注（插件风）**：
  - 高亮文本：`"The value of the Madelung constant is of central importance"`
  - 批注：`[定] Madelung常数决定离子晶体静电能，NaCl 1.747565`
  - **问题**：原文是废话，批注缺中文译名，也没给出 α 的定义式和平衡晶格能公式。
- **好批注（学术精炼风）**：
  - 高亮文本：`"The total lattice energy of the crystal of 2N ions at their equilibrium separation R₀ may be written, using (20) and (23), as"`（或紧邻平衡能公式句）
  - 批注：`[性] Madelung energy=马德隆能与平衡晶格能：由 dU_tot/dR=0 消去短程排斥参量 λ，得 U_tot(R₀)=−Nαq²/R₀·(1−ρ/R₀)；因 ρ≈0.1R₀，马德隆库仑吸引占晶格能约 90%，排斥修正占 10%。`

## 5. 标准执行工作流（Workflow）

1. **定位与精读原文**：
   - 用 `zotero_get_item_children` 获取 PDF 的 `attachment_key`。
   - 用 `zotero_read_pdf_pages` 逐页读取目标章节（注意区分 **PDF 物理页码** 与 **书印页码**，`zotero_create_annotation` 的 `page` 参数始终传 **1-indexed PDF 物理页码**）。
   - 若文本提取提示公式/图表乱码，对该页调用 `zotero_get_page_layout(attachment_key, page)` 查看图表坐标，必要时用 `zotero_read_pdf_pages(..., format='image')` 读图确认公式。
2. **规划本章标注链**：
   - 按小节先列出结论与观点清单（定义、结果式、判据、机制、验证），再逐项找原句或公式下手，过滤掉所有报幕句和过程性内容。
3. **执行打标**：
   - 文字高亮：`zotero_create_annotation(attachment_key, page, text=..., color=..., comment=..., tags=[...])`。传入的 `text` 必须与 PDF 提取文本层精确匹配（避开跨页断词或乱码公式符号）。
   - 图表/公式框选：先调 `zotero_get_page_layout(attachment_key, page)` 拿到目标 Figure/Table 的 `rect=[x, y, w, h]`，再调 `zotero_create_annotation(attachment_key, page, rect=..., color=..., comment=..., tags=[...])`。
4. **回查校验**：
   - 打完后调用 `zotero_get_annotations(item_key)` 检查页码、颜色、前缀、中英对照及 Unicode 纯文本公式是否完整无误，并做脉络回查：按页码通读一遍，能否不断链地复述每节推导。
