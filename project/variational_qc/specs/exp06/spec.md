## Part I — Scientific Description

### 1. Objective

在真机目标比特（S04）上执行 S03 `p=1` 最优电路的 `Q` 观测量测量，
产出 D08a/b 真机图层（两线各一张 `Q` 图；模拟机 `p=1,2` 曲线 + 真机 `p=1`
连续窗口散点 + 误差棒；共用端点 max 归一化后比 raw 值与趋势，
判据以 `r` 为主，见 `POST-002`），自含 S05（读出分配矩阵）。
另在 S02 三相代表点位执行 `p=1` 相匹配电路的 `Z` 基测量组 `Ŝ(q)`，
产出 D03 真机图层（三点各一条，与模拟机同图同归一化对比）。
测量按“单位”累计：一个单位 = 两线同窗口 `30` 点
（`15` 个 `s` × `δ∈{0.85,−2}`，每个 `s` 先 `0.85` 后 `−2`）
各 `1024` shots + 当单位 `1` 次 S05 标定；单轮 `500` 单位跑满，
中途不截停不结算，收齐后按窗口内共用端点搜最优偶数长度窗口并报告
（report-only，不设达标即停，`Q12`、`Q14`）。v2 分线数据整体归档，
不与 v3 联测数据混存。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 测点（`PRE-001`）：`δ=−2` 与 `δ=0.85` 两线，每线 `15` 点
  （S01 网格每 `7` 点取 `1`：`s_idx=1,8,…,99`，`s=0.01–0.99` 步长 `0.07`）；
  每点只测 `p=1`（真机只进 `p*=1`，不做层间比较，`POST-002`）。
- 电路参数：每 `(δ,s)` 取 S03 同点 `p=1` 的最优 `(θ*,a*)`（三路取最小的
  获胜路；S03 无此点则该点判 invalid，不另做优化，`PRE-002`）。
- 目标比特（只用 top1，并列者不用；用户 2026-10-04 确认，`PRE-003`）：
  - 平庸 / Néel 初态：S04 冠军 `8` 链，开链 `coupling_map`。
  - 拓扑初态：冠军环内最优 `8`-子链（D07c Rank1，取值以新 S04 为准）
    为 `8` 计算比特；首尾单态（`0–7` 对）在逻辑 `0–7` 上正常摆，
    `coupling_map` 取环状（子链 `7` 边 + `0–7` 闭合边），
    经由环剩余 `2` 比特的绕行由转译器完成——该绕行是本实验定义的
    link 语义，不判转译 invalid（`INV-003`）。
  - 注：run1 快照的具体比特表（冠军链 `[77,…,70]`、D07c Rank1 子链）仅为
    当时取值，不属合同；exp05 重跑落盘新 S04 后以新值为准（见 T008）。
- 转译：`qiskit`，`optimization_level=3`，`coupling_map` 显式传入
  （上条），`basis_gates` 由 plan 定并记入 manifest（`PRE-004`）。
- 观测量：`Q`（定义见 `docs/experiment-notes/topological_op.md`，
  `Q=4/3−2Ô_str−(4/3)Ŝ(π)`）。`S(π)` 与 string 皆为全 `Z` 对角，
  每点只需 **1 个 estimator 电路**（VQE 态制备 + `Z` 基测量）；
  同一批采样先做 S05 缓解得联合分布，再组 `Ŝ(π)`、`Ô_str`、`Q`
  （不单独标定，`PRE-005`）。每点 shots `1024`；
  重复由“测量单位”承担（本条下款），单位内误差为 multinomial 解析
  标准误经 `Q` 定义传播（存档备查，`POST-001`）。
- 测量单位（`PRE-005`）：**两线同窗口 `30` 点（`15` 个 `s` ×
  `δ∈{0.85,−2}`；每个 `s` 先 `δ=0.85` 后 `δ=−2`，时间交错以共漂移）
  各测一次（`1024` shots）+ 当单位 `1` 次 S05 标定（`2` 电路，全 `0` /
  全 `X` 制备，`1024` shots）**，共 `32` 电路同批提交；单位即重复、
  即 S05 批次。展示曲线只用最优窗口内单位的逐点平均（`POST-002`）。
- 读出缓解（S05，`PRE-006` / `POST-004`）：逐需读出比特（`8` 计算比特）
  各标定 `2×2` 分配矩阵（制备 `|0⟩` / `|1⟩` 各一电路，定义见
  `docs/experiment-notes/readout_mitigation.md`）；`8` 比特可同时测量，
  故每单位只需 `2` 个标定电路（全 `0` 制备 + 全 `X` 制备，一次给出
  `8` 比特各自的两列），与正式电路同 shots；quark 平台自带读出矫正
  必须关闭（`correct=False`，平台侧键名；防双重矫正干扰；缓解后加非负约束
  再算观测量，`INV-001`）。
- 轮次与上限（`PRE-007`）：v3 联测为单轮 `500` 单位（`16000` 电路任务），
  Baihua 整批提交，中途不截停、不结算、不升级判据；
  `500` 单位收齐后搜索窗口并报告（端点按窗口内规则定，`POST-002`）。
  v2 分线数据（dm2 正式 + d085 在途）整体归档为 `protoV2`，
  不与 v3 联测数据混存，不进 v3 窗口搜索。
  v3 跳过试水轮（用户 2026-10-26 决定，见 `Q12`），直接正式。
- 两步闸门与落盘沿用 exp05 模式（`INV-004`）：每轮离线预览打印账单 →
  人工确认后提交；拓扑快照记 `calibration_time`；逐单位增量落盘，
  中断续跑只补缺失；提交 / 收回逐任务对账（`POST-006`，`task_id` 清单留存）。
- D03 真机三点（`PRE-008`）：S02 三代表点 `(0.01,−2)/(0.99,−2)/(0.59,0.85)`；
  每点取该点 D09 `p=1` 获胜分支初态 + S03 同点 `p=1` 最优 `(θ*,a*)`；
  `Z` 基 `1024` shots + 当点 S05 标定（`2` 电路）；`S(q)` 由全部 `⟨ZiZj⟩`
  Fourier 组出再除以 `L`（与模拟机同归一化 `Ŝ=S/L`）；三点各独立测量，
  误差棒 multinomial 传播备查。

### 3. Outputs

- D08a/b 真机图层：每单位每点真机 `Ŝ(π)`、`Ô_str`（缓解后联合分布组出）；
  每单位独立存档原始 counts、缓解前观测量、缓解后两 hat 量（三者缺一不可），
  另存单位内 multinomial 传播标准误（备查）。
- 共用端点（v3）：每个展示窗口用自己 `30` 点 pooled 逐点均值的
  top-1 最大值记 `S_max`、`O_max`（Q14，两线共用同一窗口端点），
  端点随窗口记入 manifest；真机侧 `Ŝ_hw/S_max`、`Ô_hw/O_max`
  （窗口内最大→`1`，最小不管），
  模拟机侧固定 hat 尺度（`Ŝ_sim=S_sim/8`、`Ô_sim=−O_sim`）不归一化，
  参照层取 `p=1`（与真机 `p=1` 同层比较；`p=2` 只作图内对照，不参与选窗）；
  两边同公式组 `Q=4/3−2Ô−(4/3)Ŝ`，组合后不做二次归一化，
  直接比 raw 值（`d_raw=mean|Q_hw−Q_sim|`）与 `r`（`30` 点 Pearson，
  `Q_sim` 取 `p=1`）。
- 展示窗口（出图用，全量单位照常存档）：累计 `500` 单位序列中的连续子段，
  长度取偶数（`10,12,14,…`，以收齐时 `N` 为上限），窗口曲线为段内单位逐点平均 +
  单位间标准误（图上误差棒）；按 `POST-002` 规则搜索（`r` 最大者，
  并列取 `d_raw` 最小，再并列取更长，再并列取更早），report-only，
  不设达标即停，不设阈值门（阈值待数据出来后再定，见 `Q12`）。
- D08a/b 叠放：S06 同线模拟机 `p=1,2` 的 `Q` 曲线（固定 hat 尺度组出，
  不归一化；`p=1` 兼作选窗参照层，`p=2` 仅图示对照）+ 真机 `p=1` 窗口散点（共用端点归一化后逐点平均 +
  单位间标准误）；散点按 D09 获胜分段着色。
- S05：每单位标定矩阵 + 单位引用，随 D08a/b 存档（`POST-004`）。
- D03 真机图层：S02 三代表点各一条 `Ŝ(q)`（`Z` 基 `1024` shots + S05 缓解后
  联合分布组出，multinomial 传播标准误备查）；与模拟机同 `q` 网格
  同归一化可直接 overlay（`POST-008`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。
