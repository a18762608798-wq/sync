# Implementation Plan: exp02 拓扑物理量

## 1. 实现思路

- 主要模块（单 `Exp02` 命名空间下文件）：`Correlators`（`ZZ` 关联矩阵 + `S(q)`）、`StringOrder`（`O_str` 对角期望）、
  `Panels`（四联组装：`Ŝ(π)` / `Ô_str` / `Q` / `~Z_R`）、`Store`（分块增量落盘 +
  断点续算 + D03/D04a–D04d 组装）、薄编排 `scripts/run_exp02.jl`、出图
  `scripts/plot_D03D04.py`（D03 三线图 + D04a–D04d 四张热力图）。
- 数据流：S01（经 `Shared01.Store` 读取）→ 逐点求关联矩阵 → `Ŝ(π)=S(π)/L`、
  `Ô_str=−O_str`、`Q` 代数组合；`~Z_R` 用本 feature 的 `ZTilde.jl` 内核独立重算；
  D03 取 S02 三坐标条目在 q 网格上求值并除以 `L` → 分块落盘 → 组装 → Python 出图。
- 网格：`s` 沿用 S01 的 99 点；`δ` 在 `[-3,3]` 上 121 点均匀（步长 `0.05`），
  与 S01 同步。
- 核心算法：`Z` 型算符在计算基下对角，期望化为振幅模方加权求和——
  `C_ij` 为 64 个 `±1` 加权和，`S(q)` 为 `C` 的离散傅里叶加权，
  string 为串算符本征值加权和，`Q` 为三数代数组合；各点完全独立。
- 关键技术选择：数值全部在 Julia；出图全部在 Python（`figure_style.py` 已收编），
  以 `.npz` 为界，Python 不重算任何物理量。

## 3. 数值与技术决策

- 数值方法：对角期望直接振幅求和 + 小矩阵代数，无稠密大矩阵、无近似；
  `~Z_R` 沿用已验证内核。理由：`L=8` 下精确且每点毫秒级。
- 精度：`ComplexF64` 振幅，关联量取实部（虚部为 roundoff，测试中断言量级）；
  硬断言阈值 `Ŝ(q)` 负值容限 `< 1e-12`、D03↔D04a `Ŝ(π)` 逐点相等（同一内核，
  bit 一致）、`Q` 恒等式残差 `< 1e-12`。
- 并行：`Threads.@threads` 按行遍历，`BLAS.set_num_threads(1)`（宪法 V）。
- 增量落盘（宪法 IV）：D04a–D04d 按 `δ` 行分块即算即存 + 完成表续算，组装为纯拼接；
  D03 量小（3×99），随行计算、独立成文件。
- 出图：matplotlib + `figure_style.py`，只读 D03/D04a–D04d 与版式元数据。
- 关键依赖：Julia `LinearAlgebra`（stdlib）、`NPZ.jl`、`JSON3.jl`（已冻结）；
  Python 侧沿用 CondaPkg（numpy + matplotlib，现成）。

以上均为实现层选择；网格、观测量定义、输出内容与验证条件沿用 spec，未改动实验语义。
