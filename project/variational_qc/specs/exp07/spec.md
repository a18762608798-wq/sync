# Feature: exp07 p=2 分支分辨真机测量与比较

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>

## Part I — Scientific Description

### 1. Objective

在真机目标比特（S04，沿用 exp06 口径）上执行 S06 `p=2` 三分支各自最优电路的 `Q` 观测量测量，
产出 D10a/b 真机三分支图层（两线各一张 `Q` 图；模拟机 `p=2` 获胜分支单线 + 真机 `p=2` 三分支散点；
端点三分支与两线共用，做 max 归一化后比 raw 值与趋势，判据以每分支 `r_a` 为主），自含 S05（读出分配矩阵）。
模拟机图层取 S06 现成 `p=2` 获胜分支数据（`q_sim_p2` 口径），不重算、不补算分支观测量。
测量按“单位”累计：一个单位 = `90` 点（`15` 个 `s` × `δ∈{0.85,−2}` × 三分支 `a`，
每个 `s` 先 `0.85` 后 `−2`，每个 `(s,δ)` 内按 triv→topo→AFM 顺序）
各 `1024` shots + 当单位 `1` 次 S05 标定；单轮 `500` 单位跑满（`46000` 电路任务），
中途不截停不结算，收齐后按窗口内共用端点搜最优偶数长度窗口并报告
（report-only，不设达标即停）。数据独立存档 `data/exp07/`，不与 exp06 混存。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 测点（`PRE-001`）：`δ=−2` 与 `δ=0.85` 两线，每线 `15` 点
  （S01 网格每 `7` 点取 `1`：`s_idx=1,8,…,99`，`s=0.01–0.99` 步长 `0.07`，与 exp06 同点）；
  每点三分支各测 `p=2`（真机不做层间比较，`POST-002`）。
- 电路参数（`PRE-002`）：每 `(δ,s,a)` 取 S06 `theta_leg` 同点 `p=2` 该分支最优参数
  （三路各自 `θ*_a`，不取三路最小；`a*` 获胜标签仅记录不决定执行分支）；
  该分支在 S06 中 `conv` 与 `stagn` 皆假则该点判 invalid，不另做优化。
- 目标比特（只用 top1，并列者不用；沿用 exp06 `PRE-003` 口径）：
  平庸 / Néel 初态用 S04 冠军 `8` 链开链 `coupling_map`；
  拓扑初态用冠军环内最优 `8`-子链为 `8` 计算比特，
  首尾单态（`0–7` 对）在逻辑 `0–7` 上正常摆，`coupling_map` 取环状，
  经由环剩余 `2` 比特的绕行由转译器完成——该绕行是本实验定义的
  link 语义，不判转译 invalid（`INV-003`）。
- 转译（`PRE-004`）：`qiskit`，`optimization_level=3`，`coupling_map` 显式传入
  （上条），`basis_gates` 由 plan 定并记入 manifest。
- 观测量（`PRE-005`）：`Q`（定义见 `docs/experiment-notes/topological_op.md`，
  `Q=4/3−2Ô_str−(4/3)Ŝ(π)`）。`S(π)` 与 string 皆为全 `Z` 对角，
  每点只需 **1 个 estimator 电路**（VQE 态制备 + `Z` 基测量）；
  同一批采样先做 S05 缓解得联合分布，再组 `Ŝ(π)`、`Ô_str`、`Q`
  （不单独标定）。每点 shots `1024`；
  重复由“测量单位”承担，单位内误差为 multinomial 解析
  标准误经 `Q` 定义传播（存档备查，`POST-001`）。
- 测量单位（`PRE-006`）：**三分支两线同窗口 `90` 点（`15` 个 `s` ×
  `δ∈{0.85,−2}` × 三分支；每个 `s` 先 `δ=0.85` 后 `δ=−2` 时间交错以共漂移，
  每个 `(s,δ)` 内按 triv→topo→AFM 顺序执行）
  各测一次（`1024` shots）+ 当单位 `1` 次 S05 标定（`2` 电路，全 `0` /
  全 `X` 制备，`1024` shots）**，共 `92` 电路同批提交；单位即重复、
  即 S05 批次。展示曲线只用最优窗口内单位的逐点平均（`POST-002`）。
- 读出缓解（S05，`PRE-006` / `POST-004`）：逐需读出比特（`8` 计算比特）
  各标定 `2×2` 分配矩阵（制备 `|0⟩` / `|1⟩` 各一电路，定义见
  `docs/experiment-notes/readout_mitigation.md`）；`8` 比特可同时测量，
  故每单位只需 `2` 个标定电路（全 `0` 制备 + 全 `X` 制备，一次给出
  `8` 比特各自的两列），与正式电路同 shots；quark 平台自带读出矫正
  必须关闭（`correct=False`，平台侧键名；防双重矫正干扰；缓解后加非负约束
  再算观测量，`INV-001`）。
- 轮次与上限（`PRE-007`）：单轮 `500` 单位（`46000` 电路任务），
  Baihua 整批提交，中途不截停、不结算、不升级判据；
  `500` 单位收齐后搜索窗口并报告（端点按窗口内规则定，`POST-002`）。
  数据独立存档 `data/exp07/`，不与 exp06 联测数据混存。
- 两步闸门与落盘沿用 exp05 模式（`INV-004`）：每轮离线预览打印账单 →
  人工确认后提交；拓扑快照记 `calibration_time`；逐单位增量落盘，
  中断续跑只补缺失；提交 / 收回逐任务对账（`POST-006`，`task_id` 清单留存）。

### 3. Outputs

- D10a/b 真机三分支图层：每单位每 `(δ,s,a)` 点真机 `Ŝ(π)`、`Ô_str`（缓解后联合分布组出）；
  每单位独立存档原始 counts、缓解前观测量、缓解后两 hat 量（三者缺一不可），
  另存单位内 multinomial 传播标准误（备查）。
- 共用端点：每个展示窗口用自己 `90` 点（三分支两线）pooled 逐点均值的
  top-1 最大值记 `S_max`、`O_max`，端点随窗口记入 manifest；
  真机侧三分支统一用该组端点归一化（`Ŝ_hw/S_max`、`Ô_hw/O_max`，
  窗口内最大→`1`，最小不管），
  模拟机侧取 S06 现成 `p=2` 获胜分支固定 hat 尺度（`Ŝ_sim=S_sim/8`、`Ô_sim=−O_sim`，
  与 exp06 `q_sim_p2` 同口径）不归一化；
  两边同公式组 `Q=4/3−2Ô−(4/3)Ŝ`，组合后不做二次归一化，
  直接比 raw 值（`d_raw,a=mean|Q_hw,a−Q_sim|`，每分支 `30` 点）与 `r_a`（每分支 `30` 点 Pearson，
  `Q_sim` 取 `p=2` 获胜分支曲线）。
- 判据以每分支 `r_a` 为主：报告三分支 `r_a` 及其均值；`90` 点 pooled `r` / `d_raw` 作诊断备查。
- 展示窗口（出图用，全量单位照常存档）：累计 `500` 单位序列中的连续子段，
  长度取偶数（`10,12,14,…`，以收齐时 `N` 为上限），窗口曲线为段内单位逐点平均 +
  单位间标准误（图上误差棒）；按 `POST-002` 规则搜索（`mean(r_a)` 最大者，
  并列取 pooled `d_raw` 最小，再并列取更长，再并列取更早），report-only，
  不设达标即停，不设阈值门。
- D10a/b 叠放：S06 同线 `p=2` 获胜分支 `Q` 曲线（灰色单线，与 D08 的 `p=2` 灰同色）
  + 真机 `p=2` 三分支窗口散点（初态本色：triv 红 / topo 蓝 / Néel 黑；
  不按 D09 获胜分段着色）。
- S05：每单位标定矩阵 + 单位引用，随 D10a/b 存档（`POST-004`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D10a/b 真机三分支图层：两线三分支同窗口 `90` 点（`15s×2δ×3a`）`p=2` 的真机
  `Ŝ(π)`、`Ô_str`（缓解后联合分布组出，multinomial SE 备查）。
- `BND-002` D10a/b 叠放比较：真机 `p=2` 三分支窗口散点与 S06 模拟机 `p=2` 获胜分支
  `Q` 曲线（灰色单线；固定 hat 尺度组出，不归一化；`q_sim_p2` 口径复用，不重算）。
- `BND-003` S05：逐需读出比特的 `2×2` 读出分配矩阵（自含，每单位 fresh）。

#### Out of Scope

- `BND-004` S01 / S02 基态与 D03–D04（shared-01、exp02）、
  D08/D09（exp04、exp06，含其真机数据；S04 比特口径只引用不重算）。
- `BND-005` 模拟机 VQE（exp04，S06 / S03 只消费不复算；
  S06 未存档的分支观测量不补算，模拟机图层只用获胜分支 `p=2` 数据）。

#### Dependencies

- `DEP-001` S06（exp04：每 `(δ,s)` 点 `p=2` 三分支各自 `θ*_a` + 获胜分支 `a*` + 获胜分支 `S(π)`、string；供真机分支参数与模拟机图层）。
- `DEP-002` S04（exp05 真机目标比特：冠军 `8` 链与冠军环 + 快照标识；沿用 exp06 口径）。
- `DEP-003` S03（exp04 最优参数视图；`a*` 标注的交叉引用，不决定执行分支）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `a ∈ {triv, topo, AFM}`：初态指标（分支）。
- `θ*_a(p=2)`：S06 中 `(δ,s)` 点 `p=2` 该分支最优参数；`a*` 为同点获胜分支标签（仅记录）。
- `r_a` / `d_raw,a`：分支 `a` 的 `30` 点 Pearson / 平均绝对差（`Q_hw,a` vs `Q_sim` 获胜分支 `p=2` 曲线）。
- `S_max` / `O_max`：候选窗口内 `90` 点 pooled 逐点均值的 top-1 最大值（三分支两线共用，各窗口独立）。
- link 语义：topo `0–7` 绕行是本实验定义的转译行为（`INV-003`）。
