## 1. 实现思路

- 主要模块（单 `Exp03` 命名空间下文件）：`SectorBasis`（`P=−2` 扇区轨道基矢 + 扇区矩阵组装）、
  `GapSolver`（逐点扇区对角化取最低两本征值 → `Δ`）、
  `Fit`（多点最小二乘二次拟合 `a+b/L+c/L²`）、
  `Store`（按 `L` 分块增量落盘 + 断点续算 + D02a/b/c 组装）、
  薄编排 `scripts/run_exp03.jl`、生产断言 `scripts/verify_exp03.jl`、
  出图 `scripts/plot_D02.py`（`1×3` 三联图 `exp03_D02.pdf/png`，`(a)(b)(c)` 标签置于各子图下方）。
- 数据流：无外部输入（自含）→ 每 `(L,s)` 稀疏组装扇区 `H` → ARPACK 最低两根 →
  `Δ_sec` → 分块落盘 → 组装 `(i)` 五 `L` 的 `Δ[5,99]`；`(ii)` 取其中
  `s∈[0.53,0.65]` 子集；`(iii)` 取 `s=0.5` 五点做 `a+b/L+c/L²` 拟合 → Python 出图。
- 核心算法：显式构造 `P=−2` 轨道基（`Z_tot=0` 比特串在
  `{I, X̄, R, X̄R}` 下全 `+` 对称化，`X̄=∏X` 为全比特翻转，
  `R` 为比特序反转），`H` 键项直接作用于比特串组装扇区矩阵为稀疏三元组
  （`SparseMatrixCSC`：对角 + 每键至多一项非对角，`nnz`/行 `~O(键数)`）；
  扇区维数 `23/252/3299/46508/677294`（`L=8/12/16/20/24`，后两者由生产 manifest 实测确认）；
  最低两本征对经 ARPACK
  （`eigs`, `nev=2`, `which=:SR`, `tol=1e-12`）求得，逐点残差硬断言
  `< 1e-10`；`L=16` 单点约 `0.09s`；`L=20` 全网格（99 点，6 worker）实测 `105s`；
  `L=24` 单点约 `1–2 min`（含重试），其 20 个 chunk 与 `L=12/16` 合计
  实测 `1942s`（6 worker）。
- 扩展路径（2026-11-04）：`MpsGapSolver` 使用 CPU 有限链 MPS/DMRG 计算
  `L > 24` 的同一 `P=−2` 能隙；ED 仍负责 `L=8,12,16,20,24` 的精确基准。
  具体模块、惩罚项、收敛判据与容量探测见 §7。
- 关键技术选择：不用全空间稠密 `H`（`L=16` 时 `65536²` 不可行，
  故不复用 `build_hamiltonian`，只复用其键集/权重/基矢约定语义）；
  不用稠密全谱对角化（实测 `L=16` 单点 `115s`，`5×99` 点不可行，
  改稀疏 ARPACK 后单点 `0.09s`，见 §5）；
  不用迭代法之外的收敛参数（ARPACK `tol` 为求解器精度，由残差断言锁定）；
  不用惩罚 `H'` 法（显式基矢构造性保证扇区纯度，无需 `λ` 选择与事后验证）；
  数值全部在 Julia，出图全部在 Python，以 `.npz` 为界，Python 不重算任何物理量。

以上均为实现层选择；`L` 取值、能隙定义、网格、`δ`、拟合方法、
输出内容与验证条件沿用 spec，未改动实验语义。

## 3. 数值与技术决策

- 数值方法：扇区矩阵稀疏三元组组装 + ARPACK 求最低两本征对
  （`ComplexF64`，`L=16` 扇区 `3299` 维、`nnz ~ 5×10^4`，单点约 `0.1s`，
  含基矢枚举与组装）；二次拟合为闭式最小二乘，无近似。
  理由：键项每行至多 `O(键数)` 非零，Krylov 法取两根毫秒级；
  稠密全谱实测 `115s`/点（干净态单线程），`495` 点不可行。
- 精度：硬断言阈值 `Δ ≥ −1e-12`（roundoff 容限，spec `Δ≥0` 的实现落实）、
  逐点本征对残差 `‖Hv−λv‖ < 1e-10`（生产门控，失败即 invalid；
  残差直接锁定所求两根，比全矩阵厄米范数更强且为 `O(nnz)`）、
  ARPACK `tol=1e-12`（求解器精度，由残差断言锁定）、拟合系数重算
  一致 `< 1e-12`（由五点数据重算 `a,b,c`）、
  `L=8` 与全空间暴力（`build_hamiltonian` + `P` 投影）最低两根一致 `< 1e-10`
  （测试层）、`L=16` 单点与稠密全谱一致 `< 1e-8`
  （测试层，一次性约 2 分钟）；
  资源守卫 `MAX_L` 保持 `26`（枚举 `O(2^L)` 的实现层护栏，不属实验定义）。
  以上只换求解路径与拟合方式，不改观测量定义与输出内容（spec `INV-003` 求解器判据本就授权 plan 定）。
- 并行：进程级并行（`Distributed.pmap`），默认 `6` 个 worker
  （`EXP03_WORKERS` 可调），每 worker `-t 1`、`BLAS.set_num_threads(1)`（宪法 V）。
  理由：ARPACK 的 Fortran 内部状态不可跨线程共享（多线程并发 `eigs` 实测触发
  `XYAUPD info=3` / 段错误），单进程只能锁串行、实际单核；独立进程各持私有
  ARPACK 状态即可线性扩展。内存实测 L=24 矩阵 `216 MB`（`nnz=8.79M`，组装 `9.3 s`），
  加 ARPACK 工作区约 `1.2 GB`/worker，`6` 进程约 `7 GB`，16 GB 机器留有余量。
- 残差重试：ARPACK 随机初值使已收敛对的残差偶发擦线（实测 L=20, s=0.01 达
  `1.02e-10`，同点重算 `1e-13`）。`solve_gap` 按 `(ncv=64, tol=1e-12)` →
  `(128, 1e-12)` → `(256, 0)` 阶梯重试，任一档满足 `RESID_TOL=1e-10` 即返回；
  合同阈值不放松，全部档失败才判 invalid。
- 增量落盘（宪法 IV）：按 `(L, 5 点)` 分块即算即存，续算按 chunk 文件是否存在判定
  （`chunk_exists`，不依赖跨进程共享的进度 JSON），组装为纯拼接；
  预计总量共 `495` 点（`5×99`），中断可恢复；
  任务顺序按 `L=8`、`12`、`16`、`20`、`24`，先在小尺寸验证全链路再跑大尺寸；
  `(iii)` 五点全部复用 (i) 同点值，无独立计算。
- 出图：matplotlib + `figure_style.py`，只读 D02a/b/c 与版式元数据。
- 关键依赖：Julia `LinearAlgebra` + `SparseArrays`（stdlib）、`Arpack.jl`、
  `NPZ.jl`、`JSON3.jl`（`Project`/`Manifest` 已更新并冻结）；
  Python 侧沿用 CondaPkg（numpy + matplotlib，现成）。

## 4. 验证方案

spec 验证条件的落实（硬断言，失败即 invalid）：

- 扇区纯度（构造层 + 测试层）：基矢代表元逐个 `popcount == L/2`；
  随机扇区矢量在 `X̄`、`R` 下不变；`L=8` 全点扇区结果与全空间暴力一致。
- 逐点：`Δ ≥ −1e-12`；本征对残差 `< 1e-10`（`nconv ≥ 2` 否则抛错）；
  无缺失、无 NaN。
- 组装：拟合 `(a,b,c)` 由存档五点重算一致；五点全部
  与 `Δ[5,99]` 的 `s=0.5` 列一致（同一计算复用，构造性保证，断言锁定）；
  D02b 子集点数与 `s∈[0.53,0.65]` 网格一致。
- 出图：三联顺序 `(a)(b)(c)` 与版式一致，三子图等大，标签置于各子图下方；
  `(b)` 横轴范围为 `[0.53,0.65]` 且无图例；`(c)` 五点 + 拟合直线与存档一致，
  图例只含截距 `a`；
  出图中所用 `Δ` 一律写全为 `Δ_sec`（含 `(a)`、`(b)` 纵轴与 `(c)` 纵轴）；
  底图坐标系与 D02a/b/c 数据一致（脚本自检断言）。
- 单元测试：轨道基构造性（维数 `>0`、代表元磁化、算符不变性）；
  `L=8` 暴力一致；`L=16` 单点稠密全谱抽查；二次拟合合成数据
  （已知二次多项式精确恢复）；`sector_hamiltonian` 非法 `L` 拒绝路径；
  ARPACK 不收敛拒绝路径（`nconv < 2` 抛错）。

- `a` 与 `0` 的偏离（相对 `b` 尺度记录）；每 `L` 最小 `Δ_sec` 及位置
  （作论文解释证据，不作通过条件）。

### 7.2 算法与可重复性

- 有限开链 $S=1/2$ MPS，当前原型不使用 QN。ITensor 算符映射为 $XX+YY=2(S^+S^-+S^-S^+)$、$ZZ=4S^zS^z$，键集与权重复用 Shared01。
- 选态哈密顿量为

$$
H_{\rm pen}=H+\lambda_S S_z^2+\lambda_X(1-\bar X),\qquad \lambda_S=100,\quad\lambda_X=50.
$$

- 用 `dmrg(H_pen, prev, psi0; weight=1000)` 依次求候选态；得到两个合格态且前序候选的收敛可核验时停止，最多 8 个。初态为固定 Néel 乘积态，随机种子为 1234。原始 $H$ 在合格候选张成空间内解广义本征问题，返回能量并重新检查组合态扇区；不使用惩罚能量充当物理能量。
- 基态至少 20 扫、激发态至少 30 扫，最多各 120 扫；相邻扫能量绝对变化小于 $10^{-10}$ 才允许提前停止。验收仍为末两扫变化小于 $10^{-8}$，不得放宽。
- 键维阶梯从 $\min(128,\chi)$ 开始倍增到指定 $\chi$；`cutoff=1e-13`。基态 noise 为 `[1e-6,1e-7,1e-8,1e-9,0]`，激发态为 `[1e-5,1e-6,1e-7,1e-8,1e-9,0]`；保留全扫能量与截断记录，最大丢弃权重须小于 $10^{-8}$。
- 原型局部求解默认 Krylov 维数 3、最多重建 1 次，已出现扫数耗尽而激发态未收敛。下一轮用 `eigsolve_krylovdim=16`、`eigsolve_maxiter=4`、`eigsolve_tol=1e-14` 改善局部求解；精度门槛不变。[ITensor 官方收敛说明](https://docs.itensor.org/ITensorMPS/dev/faq/DMRG.html)建议对缓慢收敛增加局部 Krylov 维数。
- CPU 每个进程使用单 BLAS 线程；独立参数点默认最多 24 个进程，容量的两个键维可用两个进程独立计算后按阶梯检查；避免嵌套线程。每个记录包含完整求解参数、代码指纹、Julia/包版本、线程数、耗时与峰值 RSS；恢复计算须匹配配置，不能因文件存在就复用旧试验。
- 反射通过反序 MPS 张量并重标物理指标计算重叠；$\bar X$ 用全链 Pauli-X MPO，$S_z^2$ 用总磁化 MPO 的乘积。两个保留态须满足 $|\langle S_z^2\rangle|,|\langle\bar X\rangle-1|,|\langle R\rangle-1|<10^{-3}$。
- 广义本征分解后的态可能混合全部候选；收敛有效性须涵盖整个参与子空间。前序未收敛候选不能被忽略后声称已得到最低两个合格态。
