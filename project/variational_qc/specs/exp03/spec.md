# Feature: exp03 附录能隙

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>

## Part I — Scientific Description

### 1. Objective

自含计算 `δ=−2`、`L=8,12,16,20,24` 的对称性能隙，产出 D02a（`Δ_sec`–`s`
全曲线）、D02b（`s∈[0.53,0.65]` 放大曲线）、D02c（`s=0.5` 处 `Δ_sec`–`1/L`
五点与 `a+b/L+c/L²` 拟合）三部分数据 + 附录图。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 系统 / 模型：SSH XXZ 链，OBC，`L ∈ {8,12,16,20,24}`，
  哈密顿量 `H(s,δ)` 定义见 `docs/theory/H.md`（`PRE-001`）。
- 能隙：对称性能隙 `Δ_sec(L,s) = E1^{(P=-2)} − E0^{(P=-2)}`
  （见 `docs/theory/gap.md`），其中 `P` 定义与扇区筛选
  （`H'=H+P`）见 `docs/theory/H.md`；
  `P=−2 ⇔ Z_tot=0、∏X=+1、R=+1`（由 `P` 定义直接得出）。
- `δ` 固定：三部分均取 `δ=−2`（`PRE-001`）。
- `s` 网格：`s=i/100`（`i=1,…,99`），即 `[0,1]` 作 101 点均匀划分后去边界，
  共 99 点；五个 `L` 共用同一网格，每 `L` 共 99 点（`PRE-002`）。
- D02a（`PRE-002`）：五个 `L` 的全部 99 点 `Δ_sec`–`s` 曲线。
- D02b（`PRE-003`）：取 D02a 网格中 `s∈[0.53,0.65]` 的子集放大展示
  各曲线的极小（极小随 `L` 增大向 `s_c=0.5` 移动并变浅），不另算新点。
- D02c（`PRE-004`）：取点 `(δ=−2,s=0.5)`（即 `i=50`），`L ∈ {8,12,16,20,24}`，
  横轴 `1/L`、纵轴 `Δ_sec`，五点全画；五点复用 D02a 同点值，不另算；
  用 `Δ_sec = a + b/L + c/L²` 对五点作最小二乘拟合，
  报告 `a、b、c`。`a` 为 `L→∞` 的能隙，理论期待 `a=0`
  （见 `docs/theory/gap.md` 有限尺寸标度一节）。

### 3. Outputs

- D02a/b/c 数据：(i) `Δ_sec[5,99]` 网格（→D02a、D02b）、
  (ii) 五点 `(1/L,Δ_sec)` + 拟合系数 `(a,b,c)`（→D02c）；
  每点附参数元数据 `(L,s,δ)`（`POST-001`）。
- D02a/b/c 图：附录能隙图（三部分合为 `1×3` 三联图 `exp03_D02.pdf`；版式由实现层安排，
  不属实验定义，`POST-002`）。
- 具体落盘格式与存储路径由 plan 确定；须保证可按 `(L,s)` 检索
  （`POST-003`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D02a/b/c：`δ=−2` 时五个 `L` 的对称能隙 `Δ_sec(s)` 网格
  （→D02a）；同一网格在 `s∈[0.53,0.65]` 的子集（→D02b）；
  `s=0.5` 处五点的 `Δ_sec` vs `1/L` 与 `a+b/L+c/L²` 拟合系数（→D02c）。

#### Out of Scope

- `BND-002` S01 / S02 基态与 D03 / D04a–D04d（shared-01、exp02，
  保持开放引用，不消费；`L=8` 即使尺寸相同也独立重算，
  因本实验量为对称扇区能隙而非全空间基态）。
- `BND-003` 能隙之外的任何观测量；VQE、真机测量与读出缓解（exp04–exp06）；
  拟设结构示意图 D06a–D06c（exp04）。

#### Dependencies

- `DEP-001` 无外部数据依赖（自含；模型与对称性定义见 `docs/theory/H.md`，
  能隙定义见 `docs/theory/gap.md`）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `Δ_sec(L,s) = E1^{(P=-2)} − E0^{(P=-2)}`：对称性能隙。
- `P=−2 ⇔ Z_tot=0、∏X=+1、R=+1`。
- 拟合式 `Δ_sec = a + b/L + c/L²`；`a` 为 `L→∞` 的能隙。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 系统：SSH XXZ 链，OBC，`L ∈ {8,12,16,20,24}`；
  三部分计算均取 `δ=−2`。
- `PRE-002` `s` 网格：`s=i/100`（`i=1,…,99`），共 99 点；
  五个 `L` 共用同一网格。
- `PRE-003` D02b：取 `PRE-002` 网格中 `s∈[0.53,0.65]` 的子集，
  不引入新点。
- `PRE-004` D02c：取 `s=0.5`（`i=50`）的五点，复用 `PRE-002` 同点值；
  用最小二乘拟合 `a+b/L+c/L²`，报告 `a、b、c`。

### D. Postconditions

定义一次成功计算完成后必须成立的条件。

- `POST-001` D02a/b/c 数据：`Δ_sec[5,99]` 网格（→D02a、D02b）；
  `s=0.5` 五点 `(1/L,Δ_sec)` + 拟合系数 `(a,b,c)`（→D02c）；
  每点附参数元数据 `(L,s,δ)`。
- `POST-002` D02a/b/c 图：附录能隙图，三部分合为 `1×3` 三联图 `exp03_D02.pdf`
  （版式由实现层安排，不属实验定义）。
- `POST-003` 具体落盘格式与存储路径由 plan 确定；须保证可按 `(L,s)` 检索。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 求解限定 `P=−2` 扇区。
- `INV-002` `Δ_sec ≥ 0`（数值容限 `Δ ≥ −1e-12`）；
  拟合系数与五点数据自洽（由数据重算 `a、b、c` 一致，`< 1e-12`）。
- `INV-003` 扇区最低两本征值须收敛至求解器精度
  （逐点本征对残差 `< 1e-10`；具体判据与阈值由 plan 定）。
- `INV-004` 无缺失、无 NaN。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `INV-002`：`Δ ≥ −1e-12`；拟合系数重算一致 `< 1e-12`；
  D02c 五点与 `Δ_sec[5,99]` 的 `s=0.5` 列逐点一致。
- `VAL-002` → verifies `INV-003`：逐点本征对残差 `< 1e-10`。
- `VAL-003` → verifies `POST-001`、`PRE-003`：D02b 子集完整
  （`s∈[0.53,0.65]` 的点数与网格一致，无缺失）。
- `VAL-004`（诊断，只记录）：`a` 与 `0` 的偏离（相对 `b` 尺度记录，
  `a≈0` 为定性期待，不作硬阈值）；每 `L` 最小 `Δ_sec` 及位置
  （作论文解释证据，不作通过条件）。
- `VAL-005`（invalid-run）→ verifies `INV-001`、`INV-004`、`PRE-002`、
  `INV-002`：求解未限定 `P=−2` 扇区；任一点缺失 / NaN；
  各 `L` 网格不一致；拟合系数与五点数据不一致——
  出现任一情况相关点（或整批）判 invalid，不得静默出图。
