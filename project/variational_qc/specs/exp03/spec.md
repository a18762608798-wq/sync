# Feature: exp03 附录能隙

## Part I — Scientific Description

### 1. Objective

自含计算 $\delta=-2$ 的对称性能隙，产出 D02a（全曲线）、D02b（局部放大）与 D02c（有限尺寸经验拟合）及附录三联图。正式论文只使用 $L=8,16,24,32$；CPU MPS/DMRG 新结果须先通过 ED 对照、目标扇区与收敛验证，才能进入正式数据。

已有 ED 结果保留作精确基准。其他尺寸只用于方法验证，不自动加入正式图或拟合；本轮不继续探测更大尺寸。四个目标尺寸尚未全部验证通过时，不以不完整数据替换现有论文结果。

### 2. Experiment / Computation Definition

- 模型：SSH XXZ 链，OBC，哈密顿量见 `docs/experiment-notes/H.md`（`PRE-001`）。
- 对称性能隙：$\Delta_{\rm sec}(L,s)=E_1^{(P=-2)}-E_0^{(P=-2)}$，目标扇区满足 $Z_{\rm tot}=0$、$\bar X=\prod_m X_m=+1$、$R=+1$。定义见 `docs/experiment-notes/gap.md`。
- 正式尺寸、ED 基准与求解方法由 `PRE-001` 定义。已有小尺寸采用 ED 精确值，MPS/DMRG 用于扩展和交叉验证；能隙定义保持一致。
- 三部分均取 $\delta=-2$，各尺寸使用 `PRE-002` 的同一参数网格。
- D02a：各正式尺寸的完整 $\Delta_{\rm sec}$–$s$ 曲线。
- D02b：复用 D02a 在 `PRE-003` 窗口内的点，不另算新点。
- D02c：复用 D02a 在 $s=0.5$ 的四点，按 `PRE-004` 拟合并报告 $a,b,c$。$a$ 是经验截距，用作热力学极限能隙的有限尺寸估计，不视为已证明的精确极限。均匀易面 XXZ 链的体理论预期临界点无能隙；近零截距仅为一致性诊断，不能独立证明临界位置、普适标度或整张相图的收敛。

### 3. Outputs

- D02a/b/c 数据：正式尺寸的能隙网格、$s=0.5$ 的四点与拟合系数，每点附参数及方法溯源（`POST-001`）。
- 三部分合为 `exp03_D02.pdf/png` 三联图（`POST-002`），具体版式由实现层安排。
- 存储格式与路径由 plan 确定；须可按 $(L,s)$ 检索并区分 ED、MPS 和验证产物（`POST-003`）。

### 4. Theory & References

- `docs/planning/experiment-map.md`：D02a/b/c 的归属与正式尺寸。
- `docs/planning/paper-outline.md`：论文数据需求。
- `docs/experiment-notes/gap.md`：能隙、有限尺寸拟合与相边界定义。
- `docs/experiment-notes/H.md`：模型与对称性约定。

### 5. Open Questions

无未解决的科学定义问题。算法是否达到验收要求由验证决定，不视为已完成。

## Part II — Specification Contract

### A. Boundary

#### In Scope

- `BND-001` D02a/b/c：`PRE-001` 正式尺寸在 $\delta=-2$ 的对称能隙全网格、`PRE-003` 放大子集及 `PRE-004` 四点拟合；方法验证结果只有满足对应验证条件后才能用于 D02。

#### Out of Scope

- `BND-002` S01/S02 基态与 D03/D04a–D04d（shared-01、exp02）。不消费其数据；即使同为 $L=8$，本实验仍独立计算对称扇区能隙。
- `BND-003` 能隙以外的观测量、VQE、真机测量、读出缓解与 D06a–D06c；本轮不重构其他实验，不增加更大尺寸或 GPU 后端。

#### Dependencies

- `DEP-001` 无外部数据依赖；模型与能隙约定见 Part I 的核心理论笔记。

### B. Notation

- $\Delta_{\rm sec}=E_1^{(P=-2)}-E_0^{(P=-2)}$。
- $P=-2\iff Z_{\rm tot}=0,\ \bar X=+1,\ R=+1$，且 $S_z=Z_{\rm tot}/2$。
- $\mathcal L_{\rm paper}$ 为正式尺寸集，$\mathcal L_{\rm ED}$ 为已有精确基准集。
- 拟合式 $\Delta_{\rm sec}=a+b/L+c/L^2$；$a$ 为经验截距。

### C. Preconditions

- `PRE-001` SSH XXZ 链，OBC，$\delta=-2$，$\mathcal L_{\rm paper}=\{8,16,24,32\}$。保留 $\mathcal L_{\rm ED}=\{8,12,16,20,24\}$ 的 ED 基准；正式数据中 $L=8,16,24$ 复用已验证 ED 值，$L=32$ 使用 CPU MPS/DMRG。其余尺寸仅用于验证，不进入正式曲线或拟合。
- `PRE-002` $s=i/100$，$i=1,\ldots,99$，各正式尺寸共用该网格。
- `PRE-003` D02b 取 `PRE-002` 中 $s\in[0.52,0.65]$ 的子集，不引入新点。
- `PRE-004` D02c 取 $s=0.5$ 的四个正式尺寸点，复用 D02a 同点值；以最小二乘拟合 $a+b/L+c/L^2$，报告 $a,b,c$。
- `PRE-005` CPU 有限链 MPS/DMRG 使用同一 OBC 模型，通过 $S_z^2$ 和 $\bar X$ 惩罚选择 $S_z=0,\bar X=+1$，再筛选 $R=+1$；最终能量按原始 $H$ 计算。键维、截断阈值、扫数、局部求解器和初态设置由 plan 明确记录。
- `PRE-006` 正式 MPS 生产前须通过 `VAL-008` 的 ED 对照，并在 $L=32,s=0.5$ 完成容量与双键维收敛检查，记录耗时、峰值内存及诊断量。只有满足 `INV-005`、`INV-006` 的点可进入 D02；任一正式尺寸不合格时不得以缩减尺寸集代替当前定义。

### D. Postconditions

- `POST-001` D02a/b/c：$\Delta_{\rm sec}[4,99]$ 网格，$s=0.5$ 的四组 $(1/L,\Delta_{\rm sec})$ 与 $(a,b,c)$；每点包含 $(L,s,\delta)$ 与 ED/MPS 方法及来源。
- `POST-002` D02a/b/c 合为附录三联图 `exp03_D02.pdf/png`；版式由 plan 安排。
- `POST-003` 数据可按 $(L,s)$ 检索；ED 原始基准与 MPS 验证记录须保留。正式结果替换须保留原产物和溯源，不将容量探测或不合格点当作正式数据。

### E. Invariants

- `INV-001` 求解限定于 $P=-2$ 目标扇区。
- `INV-002` $\Delta_{\rm sec}\geq0$，数值容限为 $\Delta_{\rm sec}\geq-10^{-12}$；从正式四点重算的拟合系数与存档之差小于 $10^{-12}$。
- `INV-003` ED 点的最低两本征对残差小于 $10^{-10}$。
- `INV-004` 正式网格无缺失、无 NaN。
- `INV-005` MPS 相邻扫能量变化与截断丢弃权重均满足 plan 的阈值，且同一 $(L,s)$ 在 $\chi$ 与 $2\chi$ 下的能隙差满足 plan 的收敛阈值；两个计算均须有效。
- `INV-006` MPS 两个保留态的 $|\langle S_z^2\rangle|$、$|\langle\bar X\rangle-1|$、$|\langle R\rangle-1|$ 均小于 plan 的对称性阈值；不合格点无效，不得补入 D02。

### F. Validation

- `VAL-001` → `INV-002`：重算拟合系数，并检查四个 D02c 点逐一复用 D02a 的 $s=0.5$ 列。
- `VAL-002` → `INV-003`：检查每个正式 ED 点的两本征对残差。
- `VAL-003` → `POST-001`、`PRE-003`：检查四尺寸全网格及 D02b 子集完整、尺寸集合一致。
- `VAL-004`（诊断，只记录）：记录 $a$ 与零的偏离及各尺寸的最小能隙和位置。近零截距和极小移动是诊断，不作硬阈值。
- `VAL-005`（invalid-run）→ `INV-001`、`INV-002`、`INV-004`、`PRE-002`、`PRE-006`：扇区不符、缺失、NaN、网格不一致、拟合不自洽或验证门控未通过时，相关点或整批无效，不得静默出图。
- `VAL-006` → `INV-005`：逐点检查扫数、截断和双键维收敛；失败则增加扫数、键维或改进求解，不降低阈值，不自动缩减正式尺寸集。
- `VAL-007` → `INV-006`：记录并断言两保留态的对称性诊断量。
- `VAL-008` → `PRE-005`、`PRE-006`、`INV-005`：MPS 与 ED 在 $L=8,12,16$ 的网格逐点对照 $E_0,E_1,\Delta_{\rm sec}$；在 $L=24$ 的代表点及已测 $L=26,28,s=0.5$ 交叉检查。代表点与差值阈值由 plan 明确记录；不完整或失败的验证不得报告全部通过。
