# experiment-map

按 paper-outline.md 拆分实验, 只列任务归属, 不含实验细节. Dxx 为论文数据产品(需求侧), 按大纲出场顺序编号, Sxx 为中间数据, exp/shared 为实验组织(生产侧), 三套 ID 独立.

> 维护规则：`docs/planning/paper-outline.md` 的 Dxx/Sxx 增删或口径变更，必须在同一次修改中同步本文件的 Data Products 与 Coverage。

## shared-01 精确基态公共数据

无对应正文图，产出 S01、S02 供 exp02、exp04 消费；S01 的精确基态与能量为 exp04 的 D11 提供保真度和能量参考。

## exp02 拓扑物理量

依赖: S01, S02. 产出: D03, D04a, D04b, D04c, D04d.

## exp03 附录能隙

自含 $\delta=-2$、$L=8,16,24,32$ 对称能隙计算，无外部依赖。产出：D02a、D02b、D02c，三者使用同一正式尺寸集。已有 $L=8,12,16,20,24$ ED 数据与 $L=26,28$ ED 单点保留作 MPS 对照；CPU MPS/DMRG 的新结果只有在扇区、收敛与 ED 对照通过后才进入正式数据。无需继续探测 $L=48,64$。

## exp04 模拟机 VQE

产出: D06a, D06b, D06c (纯示意, 无数据依赖), D08a, D08b (与 exp06 共建), D09a, D09b (与 shared-01 共建), S06 (自含全结果, D08 模拟机图层底数),
及 S03 (S06 的 θ* 视图, 供 exp06 消费)。另依赖 S01，产出 D11（正文数值表与文字使用的验证数据，无图像）；D11 不改变 S06/S03，也不改变 exp06/exp07 的参数来源。

## exp05 真机优质比特

产出: S07a, S07b, S07c（落盘文件名沿用 exp05_D07a/b/c.npz），及 S04 供 exp06 消费.

## exp07 p=2 分支分辨真机测量

依赖: S06（三分支 $p=2$ 各自最优参数与模拟机 $p=2$ 图层）, S03（获胜分支标注）, S04（目标比特，沿用 exp06 口径）. S05 自含在本实验内. 产出 D10a–b 真机三分支图层（与 exp04 共建；模拟机图层取 S06 现成 $p=2$ 获胜分支数据，不重算）.

## exp06 真机测量与比较

依赖: S03, S04, S06 (D08a–b 组装读 S06 做模拟机图层). S05 自含在本实验内. 共建 D08a–b (与 exp04). D03 真机三点独立测量组 $\hat S(q)$（与 exp02 模拟机图层同图对比）.
