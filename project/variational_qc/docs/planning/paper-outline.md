# paper-outline

阐述论文的主要结构与内容；本文是唯一的论文规划入口。

本页链接的实验笔记记录 Exp 使用的模型、公式与计算约定。撰写正式理论正文时，先检索并阅读相关文献、核验其适用条件，再独立组织论证并与实验定义核对。现有 Dxx / Sxx 编号与产出归属保持稳定。
