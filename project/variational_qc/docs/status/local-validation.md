## exp03 拟合重组装（已处理）

初次校验时，历史二次项系数与本机法方程复算结果相差 $4.3059\times10^{-12}$ ，超出 `INV-002` / `VAL-001` 的 $10^{-12}$ 容限。该差异不能据此归因于缺少 ECC；本次没有开展内存硬件故障诊断。

2026-11-02 经用户批准，先备份旧 NPZ、manifest、PDF 与 PNG，再从现有 100 个 chunk 重组装 `data/exp03/exp03_D02.npz`，并刷新 manifest 与 D02 图。结果：

- 全部 495 个能隙值及拟合输入数组逐位不变；100 个 chunk 的 SHA-256 校验值不变。
- NPZ 中仅 `fit_a`、`fit_b`、`fit_c` 三个字段变化；没有重新求解正式网格。
- 拟合内核、实验 spec、验证脚本及 $10^{-12}$ 容限均未改变；本机三个系数的复算差异均为 $0$ 。
- `scripts/verify_exp03.jl` 输出 `VERIFY-EXP03-OK`；D02 图已重新生成，实际有效字号约为 8.3 pt，且 PDF 字体已嵌入。
- 再次运行 120 项独立重算断言全部通过；五种尺寸的抽样能隙与历史网格最大差异约为 $2.13\times10^{-13}$ 。shared-01、exp02、exp04 正式产物校验也再次通过。

备份和审计位于 `data/validation/exp03-refit-20261102-091918/`：`data/`、`figs/` 保存旧版本，`baseline.json` / `verification.json` 保存校验记录，`after-smoke/summary.json` 记录重组装后的新计算与拟合检查均通过。新 manifest 保留旧 manifest 的溯源信息，并明确原始本征值未重算。

本次是当前环境下的派生数据一致性刷新，不是对法方程跨平台稳定性的改进。以后如需跨平台严格复现，应另行评估稳定的最小二乘实现，而不是放宽现有验收阈值。
