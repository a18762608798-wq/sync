# Python 字典与 JSON 序列化

**日期**: 2026-08-04 15:16
**分类**: 编程/Python
**标签**: #Python #json #序列化

## 背景

讨论如何把 Python 字典对象存储为 JSON 文件，以及 key/value 的类型要求和 json 模块的非标准行为。

## 内容

### 基本用法

```python
import json

d = {"name": "alice", "age": 20, "scores": [90, 88]}
# dumps 返回字符串
s = json.dumps(d, ensure_ascii=False, indent=2)

# dump 写入文件对象
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(d, f, ensure_ascii=False, indent=2)

# 读回 dict（loads 读字符串，load 读文件，文件需用文本模式打开）
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```

- `dumps` = dump string，返回字符串；`dump` 直接写入文件对象，返回 `None`。`loads`/`load` 同理。
- 文件必须用文本模式打开（不能用 `"wb"`/`"rb"`）。

### key 的要求

- 仅字符串键才是标准 JSON。非字符串 key 会被**自动转成字符串**：`1` → `"1"`，`True` → `"true"`，`None` → `"null"`，`(1,2)` → `"[1, 2]"`。
- 转换不可逆：读回后所有 key 都是 str。建议直接用字符串 key。

### value 的要求

- 支持：`str`、`int`、`float`、`bool`、`None`、`list`、`dict`、`tuple`（自动转 list）。
- 不支持的（`datetime`、`bytes`、`set`、自定义对象）抛 `TypeError`，需用 `default=` 参数：

```python
import datetime

def default(o):
    if isinstance(o, (datetime.datetime, datetime.date)):
        return o.isoformat()
    raise TypeError(f"不可序列化: {type(o)}")

json.dumps(d, default=default)
```

### 非标准扩展（JS 兼容超集）

- Python 默认 `allow_nan=True`：`NaN` / `Infinity` / `-Infinity` 会原样写入，产出**非标准 JSON**，但 JS 的 `JSON.parse` 能读；Python↔Python 自写自读没问题，严格 JSON 消费者会报错。
- 严格模式：`json.dumps(d, allow_nan=False)` → 遇 `NaN`/`Infinity` 抛 `ValueError`。
- 标准 JSON 不保证键顺序；Python 3.7+ dict 保序写入读回也保序，属实现行为而非规范承诺。

## 要点

- `json.dumps()` 返回字符串，`json.dump(obj, file)` 写文件，`json.loads()` 读字符串，`json.load(file)` 读文件。
- JSON 只认字符串键；非字符串 key 自动转字符串且无法还原。
- 序列化 `datetime` 等类型需自定义 `default` 函数。
- 与严格 JSON 消费者交换数据时设 `ensure_ascii=False`（否则中文变 `\uXXXX`）并考虑 `allow_nan=False`。
