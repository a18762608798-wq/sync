# zip() 返回元组迭代器

**日期**: 2026-08-04
**分类**: 编程/Python
**标签**: #python #内置函数 #迭代器 #zip

## 背景

在 `var_optimization.py` 的重构中使用 `zip(orders, max_steps)` 将两个等长列表同步遍历，每个 `order` 对应各自的 `max_s`。对话中澄清了 `zip()` 的返回值类型。

## 内容

`zip(a, b)` 返回一个**元组迭代器**（iterator of tuples），不是字典。每次迭代产出一个 `(a[i], b[i])` 元组。

```python
list(zip([1, 2], [2, 3]))  # → [(1, 2), (2, 3)]
list(zip("ab", "cd"))      # → [('a', 'c'), ('b', 'd')]
```

解包用法：

```python
for order, max_s in zip([1, 2], [3, 4]):
    print(order, max_s)    # 1 3 然后 2 4
```

若想转成字典需显式调用 `dict(zip(keys, values))`。

## 要点

- `zip()` 返回元组迭代器，不是字典
- `for a, b in zip(list_a, list_b)` 用于同步遍历两个等长序列
- 转字典用 `dict(zip(...))`
