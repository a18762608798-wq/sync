# scipy optimize 的 tol 与 ftol 区别

**日期**: 2026-08-08 17:07
**分类**: 编程/Python
**标签**: #scipy #optimize #收敛判据 #tol #ftol

## 背景

`scipy.optimize.minimize` 的 `options` 里，COBYLA 等无梯度优化器用 `tol`，SLSQP 等梯度优化器用 `ftol`，混用会报 `Unknown solver options`。

## 内容

### 核心区别

| | `tol` | `ftol` |
|---|---|---|
| 含义 | 广义收敛容忍度 | 目标函数值的相对变化容忍度 |
| 判断对象 | 由优化器定义（梯度/步长/目标变化等综合）| 只盯目标函数值的下降 |
| 适用 | COBYLA、Powell、Nelder-Mead（无梯度）| SLSQP、L-BFGS（梯度）|

- `ftol`：相邻两次迭代目标函数值变化 < ftol 即收敛。
- `tol`：不同优化器语义不同，COBYLA 里还隐含对约束/可行域的要求。

### 谁更严格

不能直接比较，因为作用对象不同。设同样数值 `1e-6`：
- `ftol` 只盯目标值，相对更容易达到（更早停）。
- `tol` 更综合，COBYLA 里含约束要求，收敛判据更"宽"。

严格性取决于你想多晚停：值越小越严格、结果越精确。

### 混用报错

给 COBYLA 传 `ftol` → `Unknown solver options: ftol`（COBYLA 只认 `tol`）。给 SLSQP 传 `tol` → 同样会警告。

## 要点

- 梯度法（SLSQP）用 `ftol`，无梯度法（COBYLA/Powell/Nelder-Mead）用 `tol`。
- 想更精确 → 调小对应判据值。
- 按方法区分传 `tol` / `ftol`，避免警告。
