# PauliEvolutionGate 对易 Pauli 演化

**日期**: 2026-08-24 11:59
**分类**: 编程/Python
**标签**: #qiskit #PauliEvolutionGate #SuzukiTrotter #transpile #CNOT计数 #SparsePauliOp

## 背景

复现 XXZ 自旋链 ansatz 时,用 `PauliEvolutionGate` 构造 $e^{-i\theta H}$($H$ 为全对易 Pauli 项之和,如 $XX+YY+ZZ$ 各键),考察 qiskit 的合成与 transpile 质量。

## 内容

### 对易时单步 Trotter 精确

```python
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.synthesis import SuzukiTrotter
from qiskit import QuantumCircuit, transpile
from qiskit.quantum_info import Operator

qc = QuantumCircuit(10)
qc.append(
    PauliEvolutionGate(H_odd, time=0.3, synthesis=SuzukiTrotter(order=1, reps=1)),
    range(10),
)
# 与 scipy.linalg.expm(-1j*0.3*H_odd.to_matrix()) 对比: 误差 ~7e-15 (机器精度)
```

`PauliEvolutionGate(SparsePauliOp, time=θ, synthesis=...)`,`synthesis` 默认 `LieTrotter`。项两两对易时 `order=1, reps=1` 即精确,无需提高 order。

### transpile 后 CNOT 数与优化级别

同一演化门 transpile 到 `{cx, rz, sx, x}` 基,`XX+YY+ZZ` 每键的 CNOT 数随 optimization_level 变化(实测,H_odd 为 4 根键):

```python
for lvl in [1, 3]:
    tqc = transpile(qc, basis_gates=["cx", "rz", "sx", "x"], optimization_level=lvl)
    print(lvl, tqc.count_ops().get("cx", 0))   # 1 -> 24 (6/键), 3 -> 12 (3/键)
```

`optimization_level=3` 下每键 $XX+YY+ZZ$ 压到 3 CNOT,达到 Vatan-Williams 最优分解(与 Yu et al. 论文式 (13) 一致);`optimization_level=1` 只给 6 CNOT/键。结论:此类门要让高优化级别(或等价的两比特 KAK 优化)生效。

### PauliList.commutes_with_all 返回索引数组

```python
H_odd.paulis.commutes_with_all(H_odd.paulis)
# 返回 self 中与 other 全部对易的项的【索引数组】, 不是布尔矩阵
# 全对易时返回 [0, 1, 2, ...]
```

判断全对易:`np.all(paulis.commutes_with_all(paulis) == np.arange(len(paulis)))`。

### SparsePauliOp 的 == 与 equiv

`SparsePauliOp.__eq__` 是逐项严格比较(含 Pauli 项排序、系数 dtype),相同物理算符可能因排序不同返回 `False`;等价判断用:

```python
H1.equiv(H2)                      # 等价判断 (推荐)
(H1 - H2).simplify()              # 差化简后应为空或系数全 0
```

## 要点

- 对易 Pauli 和: `PauliEvolutionGate` 单步 `SuzukiTrotter(order=1, reps=1)` 精确无误差。
- transpile 到 CX 基: `optimization_level=3` 才能把每键 XX+YY+ZZ 压到 3 CNOT 最优;level=1 是 6 CNOT。
- `commutes_with_all` 返回索引数组; `SparsePauliOp` 等价判断用 `.equiv()`,不用 `==`。
