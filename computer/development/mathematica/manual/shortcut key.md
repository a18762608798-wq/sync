根据 Wolfram 官方文档，Mathematica 的主要快捷键按功能分类如下：

### 一、文件操作

- **关闭当前笔记本**：`Ctrl + F4` 

### 二、编辑操作

- **重做**：`Ctrl + Y` 
- **全选**：`Ctrl + A` 
- **查找**：`Ctrl + F` 
- **查找下一个**：`F3` 
- **注释/取消注释**：`Alt + /`

### 三、计算与求值

- **计算当前单元**：`Shift + Enter` 或数字小键盘 `Enter` 
- **原地计算**（替换选中表达式为结果）：`Shift + Ctrl + Enter` 
- **子会话中计算**：`F7` 
- **中止计算**：`Alt + .` 

### 四、数学排版（核心快捷键）

- **上标**：`Ctrl + ^` 
- **下标**：`Ctrl + _` 
- **分数**：`Ctrl + /` 
- **平方根**：`Ctrl + 2` 

### 五、特殊字符输入（使用 `Esc` 键）

- **虚数单位 `i`**：`Esc` + `ii` + `Esc` 
- **自然常数 `e`**：`Esc` + `ee` + `Esc` 
- **圆周率 `π`**：`Esc` + `p` + `Esc` 
- **无穷大 `∞`**：`Esc` + `inf` + `Esc` 
- **积分符号 `∫`**：`Esc` + `int` + `Esc` 
- **求和符号 `∑`**：`Esc` + `sum` + `Esc` 
* 函数同理 $\sqrt 2$: `Esc` + `2` + `Esc`
 * right arrow: -

### 六、单元操作

- **切换单元组展开/折叠**：`Ctrl + {` / `Ctrl + }` 
- **展开/折叠所有单元组**：`Shift + Ctrl + {` / `Shift + Ctrl + }`

根据 Wolfram 官方文档，Mathematica 的快捷键体系较为丰富，以下补充您提到的**矩阵/表格生成**及其他重要快捷键（按功能分类）：

### 一、矩阵与表格操作（核心补充）
| 快捷键                           | 功能          | 说明                   |
| ----------------------------- | ----------- | -------------------- |
| `Ctrl + ,`                    | **增加列**     | 在光标当前位置插入新列          |
| `Ctrl + Enter`                | **增加行**     | 在光标当前位置插入新行          |
| `Ctrl + Space`                | **退出表格/矩阵** | 从当前单元格移出至表格外部        |
| `Insert ▷ Table/Matrix ▷ New` | 创建带边框矩阵     | 通过菜单创建可视化表格（无默认快捷键）  |

> **操作示例**：输入 `{` 后按 `Ctrl + ,` 生成 1×2 表格，再按 `Ctrl + Enter` 扩展为 2×2 矩阵。

### 二、画布与图形快捷键

- `Ctrl + 1`：新建画布（New Canvas） [[64]]
- `Ctrl + D`：在画布与普通单元间切换 [[66]]
- `Ctrl + 2`：开始内嵌单元（Inline Cell） [[64]]

### 三、代码辅助与智能输入

- `Ctrl + K`：**补全函数名**（Complete Selection） [[53]]
- `Shift + Ctrl + K`：**插入函数模板**（Make Template），自动填充参数占位符 [[93]]
- `Ctrl + Shift + Space`：在部分插件中插入函数特定选项 [[24]]
- `Alt + Ctrl + '`：图标化/取消图标化选中内容（Iconize） [[53]]

### 四、特殊字符输入（Esc 序列）

| 操作 | 效果 | 用途 |
|------|------|------|
| `Esc` + `tr` + `Esc` | 转置符号 `` | 矩阵转置 `A` 等价于 `Transpose[A]` [[101]] |
| `Esc` + `ct` + `Esc` | 共轭转置 | 适用于复数矩阵 [[99]] |
| `Esc` + `p` + `Esc` | π | 圆周率 |
| `Esc` + `inf` + `Esc` | ∞ | 无穷大 |
| `Esc` + `int` + `Esc` | ∫ | 积分符号 |
| `Esc` + `sum` + `Esc` | ∑ | 求和符号 |

### 五、格式与导航

- `Ctrl + Shift + N`：转换为 StandardForm（标准形式） [[89]]
- `Ctrl + Shift + T`：转换为 TraditionalForm（传统数学形式）（无法接;） 
- `Ctrl + .`：逐步扩展选择范围（可用于选中整个单元） [[86]]
- `Alt + Enter`：在当前单元下方插入相同样式的新单元 [[11]]
- `Shift + Ctrl + B`：检查括号/结构平衡 [[53]]

### 六、其他实用快捷键

- `Ctrl + (` / `Ctrl + )`：开始/结束内嵌单元 [[66]]
- `Shift + Ctrl + {` / `}`：折叠/展开所有单元组 [[84]]
- `Ctrl + =`：启用自然语言输入（Wolfram|Alpha 模式） [[104]]
