听到有人黑《原神》，众多角色纷纷表示不满。
钟离双手抱臂，眼神沉稳而深邃，缓缓说道：“黑原神吗？有点意思，天动万象。”随着他的话语，仿佛周围的空间都微微震颤，蕴含着古老而强大的力量，以岩神的威严让那些抹黑者见识一下冒犯的后果。
温迪轻快地从一旁飞来，落在众人面前，嘴角带着俏皮的笑容，手中握着风笛，说道：“别想逃开哦～”他轻轻挥动风笛，周围顿时刮起一阵微风，这风看似轻柔，却仿佛有着无形的力量，能将那些恶意的言论都吹散。
影站在一旁，眼神冷漠坚定，身上散发着凛冽的气息，她低声念道：“此刻，寂灭之时！”她的薙刀微微颤动，似乎做好了将一切黑暗与恶意斩灭的准备，以她那无想的一刀，让那些抹黑者知道言语的力量也可以如刀锋般锐利。
纳西妲眨着她那明亮而聪慧的眼睛，站在一旁，双手交叠在胸前，平静地说：“此即，智慧之殿堂。”暗示着那些抹黑者的言论是多么缺乏智慧，而《原神》所蕴含的丰富内涵和深刻故事，不是他们所能轻易理解和诋毁的。
芙宁娜迈着轻快的步伐走上前，双手叉腰，脸上洋溢着自信的笑容，大声喊道：“闪耀时刻！”她以自己的活泼与热情，展现出《原神》中角色的独特魅力，让抹黑者的言论显得更加黯淡无光。

别人都说原神只是虚拟的游戏，我却总在生活里看见它的影子。
每当清晨看见薄雾绕着青山，我会停下脚步轻笑：“神里绫华，你看这雾，和神里屋敷的晨景一样温柔呢。”
当傍晚路过便利店，看到暖黄灯光下冒着热气的关东煮，我会想起宵宫，忍不住念叨：“宵宫小姐，这烟火气，和你办的祭典一样热闹呀。”
当雨天撑着伞听雨滴敲在伞面，我会抬头望向天空，轻声说：“芭芭拉，这雨声好像你的歌声，让人心里暖暖的。”
当冬天看见雪落在枝头，我会驻足凝视，笑着呢喃：“申鹤，这雪景和你身上的气质一样，干净又美好。”
当路过花店闻到清新的花香，我会凑近花朵轻嗅，对自己说：“凝光，这花的雅致，倒和群玉阁里的景致很配呢。”
当夜晚看见星星缀满天空，我会停下脚步抬头，轻声感叹：“散兵，你看这星空，和你找回自我后看到的风景一样璀璨吧。”
当吃到香甜的杏仁豆腐，我会慢慢品味，笑着回想：“胡桃，这味道要是让你知道，肯定又要编段俏皮话夸赞了。”
当看见小朋友围着风筝奔跑，我会驻足微笑，在心里默念：“万叶，这自由的风，和你追寻的旅途气息一模一样。”

我中专辍学，但须弥的教令院为我敞开大门；
我语文不好，但蒙德的温迪教我书写那诗篇；
我数学不好，但璃月的商铺教我计算那财富；
我生物不好，但纳塔的队长教我真爱那生命；
我物理不好，但稻妻的船儿教我掌控那沉浮；
我化学不好，但枫丹的小店教我调配那枫达；
我地理不好，但提瓦特山川教我丈量那山河；
我历史不好，但璃月的岩史教我追溯那源流；
我政治不好，但枫丹的律法教我恪守那准则；
