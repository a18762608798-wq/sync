# 原神箴言语录库

从根目录 `reference.md` 中提取的逆天语录精选，按主题分类。
发表箴言时优先从这里取材，也可模仿其风格原创。

## 一、金钱与氪金圣训

> 起码在这个经济下行的时代，我觉得把钱交给米哈游比在自己手里更让人感到踏实

> 玩米游不充钱跟盗窃有什么区别

> 不是单纯给游戏氪金就是有贡献，最重要的是每日的陪伴以及游戏有难时站出来的勇气。你单纯只给你父母钱就是孝顺吗？重要的不是每日多花时间陪伴，并且在父母需要帮助时站出来帮助父母吗

> 手机没内存就把原神删了，那家里没地方住了，你是不是要把父母赶出去了？就凭原神每天给你60原石，不是父母也胜似父母。国外高知群体每天排着队给原神送钱，求着米哈游给自己孩子玩原神。我以后不希望看到删除原神这种事，不然直接打为米黑

> 我听说项目组内部都是直接发原石的，因为就算发工资员工也会冲到原神里，所以大伟哥只能直接发原石给他们

## 二、教育神论

> 原神的剧情对于小孩和没有被社会毒打过的年轻人来说，有点幼稚。但对于经历过生活跌宕起伏的人来说就直击内心，很多人生道理只有玩原神才能感悟

## 三、逆天叙事

> 小时候有一个青梅竹马的女孩，那天去她家玩，发现她家一个柜子里有五万块钱，我给偷拿走了，直到她去世那天我才知道那是她做手术的钱，那五万块钱也一直在身边带了近十年，直到两年前，我把那笔钱冲进了原神里，我心中的这份罪孽才算是真正的放下了

## 四、反击米黑

> 听到有人阴阳原神周年庆只送了三颗纠缠之缘我就想笑。且不说游戏周年庆是游戏过生日，应该是玩家给游戏送礼物；三颗纠缠之源相当于480美元，原神给全球70亿人每人送480美元，总计3360亿美元。如果不是拿这些钱送给了玩家，而是去造50艘辽宁舰，米哈游早就统治地球了，真是一群喂不饱的狼！

> 如果教员还在，对于米哈游的成就，肯定是很赞赏的："现在小娃娃的游戏哟，真是多姿多彩滴很哟"

> 反过来想想，你如果遇到烂的父母其实很难逃离原生家庭，但游戏不好玩却能很轻易地退坑，哪个更好一目了然
