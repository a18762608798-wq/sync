# save

## Auto web save

保存方法主要有：

| 当前内容       | 推荐方式                       |
| ---------- | -------------------------- |
| 出版商上的论文详情页 | 直接左键，使用网站专用翻译器             |
| 只有 DOI     | 魔术棒输入 DOI                  |
| 默认保存信息错误   | 尝试 DOI 或 Embedded Metadata |
| 浏览器里只有 PDF | 保存 PDF，再检查元数据              |
| 新闻、博客、政策网页 | Web Page with Snapshot     |
| 只收藏一个网址    | Web Page without Snapshot  |
| 搜索结果中有多篇论文 | 文件夹图标批量选择                  |

使用 zotero 浏览器插件保存顺序：

```text
网站专用翻译器
    ↓
DOI
    ↓
Embedded Metadata
    ↓
Web Page with Snapshot
```

## Manual Save

Web 导入壳子之后把pdf拉进去(添加文件)就可以了.
