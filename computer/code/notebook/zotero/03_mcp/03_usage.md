# usage

## 检查连接

```bash
opencode mcp list
```

## 功能

### 读取功能

例如:

```text
使用 zotero MCP 搜索我的文献库，列出最近添加的 5 篇文献。
使用 zotero MCP 查找标题或摘要中包含 transformer 的论文。
使用 zotero MCP 找到《论文标题》，读取它的摘要和 PDF 批注。
```

### 语义搜索

前提:

```text
Zotero 桌面程序正在运行；
已开启“允许其他应用程序与 Zotero 通信”；
配置中是字符串形式的：
```

例如:

```text
使用 zotero MCP 的语义搜索，找出与“随机测量纠错”概念相关的论文，
不要只匹配标题关键词。
```
