# git add -A 参数说明

**日期**: 2026-07-20
**分类**: 工具/Git
**标签**: #git-add #git #--all

## 背景

执行 `git add -A` 提交代码时，确认该参数的作用。

## 内容

`git add -A`（`--all` 的缩写）将**整个仓库**中的所有变更（新增、修改、删除）一次性暂存到索引区。

与 `git add .` 的关键区别在于作用范围：

| 命令 | 作用范围 |
|------|---------|
| `git add -A` / `git add --all` | 仓库根目录，无论当前在哪个子目录执行 |
| `git add .` | 当前目录及其子目录 |
| `git add -u` | 仅暂存已跟踪文件的修改和删除，不含新增 |

常用组合：
```bash
git add -A          # 暂存所有变更
git add -A -v       # 添加 verbose 输出，显示每个文件的状态
git add --all       # 等价于 -A
```

## 要点

- `-A` 作用于整个仓库，不受当前工作目录影响
- 同时暂存新增、修改和删除三类变更
- `git add .` 是 `-A` 的子集，仅限当前路径
