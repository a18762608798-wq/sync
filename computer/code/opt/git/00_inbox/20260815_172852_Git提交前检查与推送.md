# Git 提交前检查与推送

**日期**: 2026-08-15 17:28
**分类**: 工具/Git
**标签**: #git #commit #push #工作流

## 背景

在 Neovim 配置完成一组功能后，需要将当前工作区的改动作为一个独立提交推送到远端。

## 内容

提交前先确认工作区、差异、最近提交和远端分支，避免把无关文件或敏感信息一并提交：

```bash
git status --short --branch
git diff --check
git diff --stat
git log --oneline -10
git branch -vv
git remote -v
```

确认范围后只暂存预期文件，提交并推送：

```bash
git add .
git commit -m "新增 CodeCompanion 浏览器预览"
git push origin master
```

推送前注意本地分支与远端的领先/落后关系；提交后可再次用 `git status --short --branch` 确认工作区干净且远端已同步。

## 要点

- `git diff --check` 可在提交前发现空白错误。
- `git branch -vv` 可确认当前分支的跟踪分支和领先/落后状态。
- 提交前应检查完整 diff，确认没有密钥、无关文件或意外改动。
