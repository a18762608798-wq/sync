# 用 skip-worktree 藏住本地专用改动

**日期**: 2026-09-05 22:29
**分类**: 工具/Git
**标签**: #git #skip-worktree

## 背景

`CondaPkg.toml` 只能提交一个版本，提交给别人看的写云端地址，自己本地要换成本机路径可编辑安装，这份本地改动绝不能推出去。

## 内容

```bash
# 藏起：之后 status、diff、push 全部跳过此文件
git update-index --skip-worktree CondaPkg.toml

# 查看：列表里该文件标小写 S 即已藏住
git ls-files -v CondaPkg.toml

# 取消隐藏
git update-index --no-skip-worktree CondaPkg.toml
```

## 要点

- 藏的是工作区相对已提交版的差异，提交出去的版本不受影响。
- 别人改了仓库里这个文件导致你拉取冲突时，先取消隐藏，处理完再藏回去。
- 别拿它当长期分支用，它只适合这种小而固定的本地覆盖。
