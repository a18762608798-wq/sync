# Julia 中生成元组的方式

**日期**: 2026-08-04 15:12
**分类**: 编程/Julia
**标签**: #julia #tuple #ntuple #元组

## 背景

用户询问 `ntuple(_ -> 2, qubit_num)` 这类生成元组的命令在 Julia 中还有哪些。

## 内容

Julia 中生成元组的常用方式：

```julia
# 1. ntuple(f, n) — 按索引调用函数生成，常用于编译期确定长度
ntuple(_ -> 2, 3)           # (2, 2, 2)
ntuple(identity, 3)          # (1, 2, 3)
ntuple(i -> 2i, 3)           # (2, 4, 6)

# 2. tuple(args...) — 直接构造
tuple(1, 2, 3)               # (1, 2, 3)

# 3. Tuple(collection) — 从可迭代对象转换
Tuple(1:5)                   # (1, 2, 3, 4, 5)
Tuple(fill(2, 3))            # (2, 2, 2)

# 4. splat 展开
(fill(2, 3)...,)             # (2, 2, 2)
```

## 要点

- `ntuple(_ -> val, n)` 是生成全同值元组的最高效方式（编译期确定长度）
- `Tuple(fill(val, n))` 需要运行时分配，效率次之
- `tuple` 是变参构造函数，适合少量已知值
- splat 展开 `(xs...,)` 也常用于拼接元组
