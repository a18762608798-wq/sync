# Julia `≈` 近似相等运算符

**日期**: 2026-07-20 20:30
**分类**: 编程/Julia
**标签**: #Julia #运算符 #浮点数

## 背景

在 QMeasPost 项目的测试代码中频繁看到 `@test psi0 ≈ [1.0+0im, 0.0+0im]`，`≈` 是 Julia 中用于浮点数近似比较的运算符。

## 内容

`≈` 是 `isapprox(x, y)` 的中缀形式（`\approx` Tab 输入）。

### 与 `==` 的区别

| 运算符 | 含义 | 适用场景 |
|--------|------|----------|
| `==` | 精确相等 | 整数、字符串、符号等精确类型 |
| `≈` | 近似相等 | 浮点数、复数、数组等存在舍入误差的场景 |

### 默认容差

- 相对容差 `rtol = √eps()`（约 1.5e-8）
- 绝对容差 `atol = 0`
- 也支持自定义：`x ≈ y atol=1e-6 rtol=1e-4`

### 在测试中的典型用法

```julia
# 浮点数数组近似相等
@test psi0 ≈ [1.0+0im, 0.0+0im]

# 标量近似相等
@test val ≈ 1.0
@test val2 ≈ -1.0

# 自定义精度
@test result ≈ 3.5 atol=1e-10
```

## 要点

- `≈` 是 `isapprox` 的中缀语法糖
- 在测试中判断浮点数结果时**必须用** `≈` 而非 `==`，否则会因舍入误差导致测试不可靠
