# Julia 用 XOR + count_ones 计算二进制汉明距离

**日期**: 2026-07-20 22:30
**分类**: 编程/Julia
**标签**: #Julia #位运算 #汉明距离 #量子计算

## 背景

在经典阴影纯度估计中，需要计算两个基态之间的汉明距离（对应位不同的个数），使用 `count_ones(state1 ⊻ (idx2 - 1))` 快速计算。

## 内容

### 核心算式

```julia
ham_dis = count_ones(state1 ⊻ state2)
```

其中：
- `⊻` = XOR（`xor` 运算符，`\xor` Tab 输入），逐位异或
  - 相同位 → 0
  - 不同位 → 1
- `count_ones` 数出二进制表示中 1 的个数

### 1-based 索引转二进制基态

Julia 索引是 1-based，而基态的二进制表示是 0-based：

```julia
state = idx - 1
```

| idx | state | 二进制 (N=3) | 对应基态 |
|-----|-------|-------------|---------|
| 1 | 0 | 000 | \|000⟩ |
| 2 | 1 | 001 | \|100⟩ |
| 3 | 2 | 010 | \|010⟩ |
| 4 | 3 | 011 | \|110⟩ |
| 5 | 4 | 100 | \|001⟩ |
| 6 | 5 | 101 | \|101⟩ |
| 7 | 6 | 110 | \|011⟩ |
| 8 | 7 | 111 | \|111⟩ |

### 枚举互异基态对的惯用写法

```julia
for idx1 in 2:length(counts)     # 所有非零基态
    state1 = idx1 - 1
    for idx2 in 1:(idx1 - 1)     # 只取 state2 < state1，避免重复对
        state2 = idx2 - 1
        h = count_ones(state1 ⊻ state2)  # 汉明距离
        # 后续计算：(-1/3)^h · n1 · n2
    end
end
```

### 子集枚举中的应用

类似的模式也常见于枚举非空真子集：

```julia
# 枚举 state1 的所有非空真子集
state1 = 0b1101
sub = state1
while sub > 0
    h = count_ones(sub)
    sub = (sub - 1) & state1
end
```

## 要点

- `state1 ⊻ state2` = XOR → 不同位为 1
- `count_ones` 数 1 的个数 = 汉明距离
- `state = idx - 1` 将 1-based 索引映射为二进制基态值
- 嵌套循环中内层 `1:(idx1-1)` 避免重复枚举基态对
