# Julia JSON 模块核心用法

**日期**: 2026-07-20 20:30
**分类**: 编程/Julia
**标签**: #Julia #JSON #序列化

## 背景

QMeasPost 项目的 `Project.toml` 中声明了 `JSON` 依赖，`src/utils.jl` 中 `using JSON`，用于解析量子测量结果的 JSON 数据文件。

## 内容

### 核心函数

| 函数 | 功能 |
|------|------|
| `JSON.parse(str)` | JSON 字符串 → Julia 数据结构（Dict/Array/Number/String） |
| `JSON.json(obj)` | Julia 对象 → JSON 字符串 |
| `JSON.parsefile(path)` | 读 JSON 文件直接解析为 Julia 数据结构 |
| `JSON.print(io, obj)` | 将 JSON 写入 IO 流 |

### 典型用法

```julia
using JSON

# 解析字符串
data = JSON.parse("{\"name\": \"qmeas\", \"qubits\": 4}")

# 序列化
println(JSON.json(data))

# 最常用：从文件读
result = JSON.parsefile("measurement_result.json")
# 等价于：
# open(f -> JSON.parse(read(f, String)), "measurement_result.json")

# 写入文件
open("output.json", "w") do io
    JSON.print(io, dict)
end
```

### `parsefile` 的实质

`JSON.parsefile(path)` = `open(f -> JSON.parse(read(f, String)), path)`

即读文件 + 解析的便捷组合，核心仍是 `JSON.parse`。

## 要点

- `JSON.parse` / `JSON.json` 是序列化反序列化的核心
- `JSON.parsefile` 是文件场景的便捷封装
- 项目中 `load_qmeas_result(test_json)` 内部大概率使用 `JSON.parsefile`
