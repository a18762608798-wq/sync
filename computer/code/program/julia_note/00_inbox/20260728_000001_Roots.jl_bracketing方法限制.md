# Roots.jl bracketing 方法的符号要求

**日期**: 2026-07-28 00:00
**分类**: 编程/Julia
**标签**: #Roots.jl #数值计算 #调试

## 背景

在使用 `Roots.jl` 的 `find_zero` 函数寻找相边界时，传入了包含 `abs()` 的函数，导致 bracketing 方法报错。

## 内容

`find_zero(f, (a, b))` 使用 bracketing 方法（如 bisection）时，要求函数在区间端点处**符号相反**：

```
f(a) * f(b) < 0
```

如果函数始终非负（如使用 `abs()`），则永远不满足 bracketing 条件。

**错误示例**：
```julia
# abs() 使函数恒 ≥ 0，无法找到符号变化
find_zero(δ -> abs(ZR(δ) - 0.5), (0, 1))
```

**修复**：
```julia
# 去掉 abs()，让函数值可正可负
find_zero(δ -> ZR(δ) - 0.5, (0, 1))
```

如果确实需要找 `|f(x)| = 0` 的根，应直接求 `f(x) = 0`，因为 `|f(x)| = 0` 等价于 `f(x) = 0`。

## 要点

- bracketing 方法要求端点函数值异号
- `abs()` 会破坏符号变化，应避免在 bracketing 搜索中使用
- 若函数在区间内不穿过零点，即使去掉 `abs()` 也会失败，需确认物理上存在零点
