# Julia `isapprox`（`≈`）精确容差算法

**日期**: 2026-07-20 22:00
**分类**: 编程/Julia
**标签**: #Julia #浮点数 #容差

## 背景

在 QMeasPost 测试文件中看到大量 `≈` 用法，深入分析了 Julia 源码中 `isapprox` 的完整容差判定逻辑，包括 `rtoldefault` 的默认值计算规则。

## 内容

### 核心判断逻辑

```julia
function isapprox(x::Number, y::Number;
                  atol::Real=0,
                  rtol::Real=rtoldefault(x, y, atol),
                  nans::Bool=false, norm::Function=abs)
    x′, y′ = promote(x, y)           # 提升到同一类型防溢出
    x == y ||                         # 完全相等直接通过
        (isfinite(x) && isfinite(y) &&
         norm(x-y) <= max(atol, rtol * max(norm(x′), norm(y′)))) ||
        (nans && isnan(x) && isnan(y))
end
```

条件：`|x - y| ≤ max(atol, rtol · max(|x|, |y|))`

### `rtoldefault` 的计算规则

```julia
rtoldefault(::Type{T}) where {T<:AbstractFloat} = sqrt(eps(T))
rtoldefault(::Type{<:Real}) = 0    # 整数类型，rtol = 0

function rtoldefault(x, y, atol)
    rtol = max(rtoldefault(real(typeof(x))), rtoldefault(real(typeof(y))))
    return atol > 0 ? zero(rtol) : rtol    # 关键：指定 atol 时 rtol 归零！
end
```

### 三种调用模式的实际效果

| 调用方式 | `atol` | `rtol` | 等效条件 |
|----------|--------|--------|----------|
| `a ≈ b`（无参数） | `0` | `√eps(T)` | **纯相对容差**：`\|a-b\| ≤ √eps · max(\|a\|,\|b\|)` |
| `a ≈ b atol=1e-7` | `1e-7` | **0**（被强制归零） | **纯绝对容差**：`\|a-b\| ≤ 1e-7` |
| `a ≈ b rtol=1e-3 atol=1e-7` | `1e-7` | `1e-3` | 两者取大：`max(1e-7, 1e-3·max)` |

### 各类型的默认 `rtol`

| 类型 | `eps(T)` | `√eps(T)` |
|------|----------|-----------|
| `Float16` | 9.77e-4 | 3.13e-2 |
| `Float32` | 1.19e-7 | **3.45e-4** |
| `Float64` | 2.22e-16 | **1.49e-8** |

### 整数特殊情况

```julia
function isapprox(x::Integer, y::Integer; ...)
    if norm === abs && atol < 1 && rtol == 0
        return x == y     # 退化到完全相等
    end
    ...
end
```

## 要点

- `atol` 和 `rtol` 用 `max` 取大，不是叠加
- **指定 `atol` 但未指定 `rtol` 时，`rtol` 会被强制设为 0**（而非保持 `√eps`）——这意味着容差完全由 `atol` 决定，不受数值大小影响
- `≈` 不能用于比较零值（`x ≈ 0` 等价于 `x == 0`），因为 `atol=0` 时 `rtol·0 = 0`
