# Julia 包管理与 Project.toml

**整理日期**: 2026-07-27
**标签**: #julia #包管理 #Pkg #Project.toml #测试 #环境配置

## 本地包的两种添加方式

```julia
# 在 Julia REPL 包管理模式中 (按 ] 进入)
] dev /path/to/QMeasPost    # 开发模式：链接源码，修改即时生效
] add /path/to/QMeasPost    # 安装模式：复制到 ~/.julia/packages/
```

也支持 GitHub URL：
```julia
] add https://github.com/user/Package.jl
] add https://github.com/user/Package.jl#branch-name
] dev ../relative/path       # 相对路径
```

### `dev` vs `add` 的区别

| 方式 | 实现 | 修改是否反映 | 适用场景 |
|------|------|-------------|----------|
| `] dev` | Manifest.toml 记录 `path = "..."` | 即时生效 | 正在开发修改的包 |
| `] add` | 拷贝到 depot 目录 | 不反映 | 只使用不修改的包 |

### Project.toml vs Manifest.toml

| 文件 | 可手动编辑？ | 内容 | 管理方式 |
|------|-------------|------|---------|
| **Project.toml** | 可以 | 包名、UUID、直接依赖、版本兼容性 | `] add`/`] dev` 自动写入 `[deps]` |
| **Manifest.toml** | **绝不手动改** | 完整依赖树、精确版本、路径 | 机器自动生成 |

### 典型工作流

```
] activate .              # 激活当前项目
] instantiate             # 安装所有依赖
] dev ../another_pkg      # 添加本地依赖
] add SomeRegisteredPkg   # 添加注册包
```

## Project.toml 依赖分类规则

### `[deps]` 三分类

| 类别 | 例子 | 写 `[deps]`？ | 写法 |
|------|------|-------------|------|
| **第三方包** | ITensors, JSON, StatsBase | ✅ **必须写** | `] add` 自动填入 UUID |
| **独立标准库** | LinearAlgebra, Statistics, Random, Test | ✅ **必须写** | 手动写入 UUID，不需要 `] add` |
| **Base 子模块** | Base.Threads, Core | ❌ **不写** | 语言内置，永远可用 |

### 标准库 UUID 的获取

```julia
using LinearAlgebra
Base.PkgId(LinearAlgebra).uuid   # "37e2e46d-..."
```

### `[compat]` 是可选的

```toml
[compat]
ITensors = "0.7"
julia = "1.10"
```

`[compat]` 不写表示不限制版本。空着整个段或只写部分依赖的约束都可以。

### Base.Threads 特殊处理

`Base.Threads` 是 `Base` 的子模块，不是独立的包：

```toml
# ❌ 错误 — Threads 不是独立的包
[deps]
Threads = "..."

# 代码中直接用
using Base.Threads
```

`[compat]` 中也无需涉及 `Threads`。线程功能依赖的 Julia 版本通过 `julia = "1.x"` 控制。

### 判断规则

不确定某个模块是否要写 `[deps]` 时：
1. 能否 `] add <包名>`？ → 能则写
2. 是标准库（LinearAlgebra, Statistics）？ → 写
3. 是 `Base.XXX` 或 `Core.XXX`？ → **不写**

## test/Project.toml 包名冲突问题

**问题**：`test/Project.toml` 中定义了与主包相同的 `name` 和 `uuid`，导致 `Pkg.develop` 失败。

```toml
# ❌ 错误写法
name = "QMeasPost"
uuid = "0eb3f2fb-1a00-44d2-b32f-d01c869429f6"

[deps]
QMeasPost = "0eb3f2fb-1a00-44d2-b32f-d01c869429f6"
```

**解决方法**：移除测试 Project.toml 中的顶层 `name` 和 `uuid`，只保留依赖声明：

```toml
[deps]
QMeasPost = "0eb3f2fb-1a00-44d2-b32f-d01c869429f6"
Test = "8dfed614-e22c-5e08-85e1-65c5234f0b40"
```

然后重新执行：
```bash
julia --project=test -e 'using Pkg; Pkg.develop(path="."); Pkg.instantiate()'
```

## 要点

- `] dev` 是本地开发的首选方式
- Project.toml 声明直接依赖（可手动编辑），Manifest.toml 不手动改
- 第三方包：`] add` 自动处理；独立标准库：手动写 `[deps]`；Base 子模块：从不写
- `[compat]` 可选，省略即不限制版本
- `test/Project.toml` 可以不设顶层 name 字段（或使用不同的名称）
