# Julia 中的取余与取模

**日期**: 2026-08-04 15:12
**分类**: 编程/Julia
**标签**: #julia #取余 #取模 #mod #rem #divrem

## 背景

用户询问 Julia 中的取余命令。

## 内容

Julia 中取余/取模相关函数：

```julia
rem(7, 3)       # 1 — 取余，结果符号与 x 相同
rem(-7, 3)      # -1
mod(7, 3)       # 1 — 取模，结果符号与 y 相同
mod(-7, 3)      # 2
divrem(7, 3)    # (2, 1) — 同时返回商和余数
```

`div` 配合 `rem` 满足 `x == div(x, y)*y + rem(x, y)`；`fld` 配合 `mod` 满足 `x == fld(x, y)*y + mod(x, y)`。

注意：`x % y` 在 Julia 中不是直接取余，而是返回 `Remainder(x, y)` 对象（延迟评估），通常在矩阵运算中用。

## 要点

- `rem`：余数符号 = 被除数符号
- `mod`：余数符号 = 除数符号（更符合数学意义的取模）
- `divrem`：一次性获取商和余数，效率更高
- `%` 返回 `Remainder` 对象而非直接计算结果
