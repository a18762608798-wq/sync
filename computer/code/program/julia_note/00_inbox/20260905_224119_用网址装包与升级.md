# 用网址装包与升级

**日期**: 2026-09-05 22:41
**分类**: 编程/Julia
**标签**: #Pkg #版本管理

## 背景

没进注册表的包只能用网址装，装完发现重跑安装命令拿不到新版，由此摸清这套机制是惰性的。

## 拿新版

```julia
using Pkg
Pkg.update("包名")
```

- `Pkg.add(url="...")` 是惰性的：装过就跳过，不去云端看，装的是第一次执行时分支的样子，之后冻住。
- 要拿新版就显式升级，上面这行会拉到跟踪分支的最新提交。
- 装进的是当前激活的环境，执行前先确认环境（`julia --project=/你的项目路径` 或 REPL 里先激活）。

## 钉住不动

```julia
Pkg.add(url="git@github.com:xxx/yyy.git", rev="提交号或标签名")
```

- 安装时指定版本点，之后升级也不会越过它。
- 跟 CondaPkg 管 Python 包一个道理：想推更新就换号，用户照常升级即跟上（见笔记《CondaPkg 的 Python 依赖管理》）。

## 要点

- 惰性的是安装命令，升级要手动喊。
- 网址装的包没有版本号概念，认的是分支最新提交或指定的版本点。
