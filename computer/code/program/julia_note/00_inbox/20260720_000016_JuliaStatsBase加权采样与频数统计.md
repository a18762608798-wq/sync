# Julia StatsBase 加权采样与频数统计

**日期**: 2026-07-20 23:10
**分类**: 编程/Julia
**标签**: #Julia #StatsBase #采样 #统计

## 背景

需要根据一个 N 维概率分布数组抽取 K 次样本并统计频数，涉及 `StatsBase` 的 `sample`、`Weights`、`counts` 三个函数。

## 内容

### 加权采样三部曲

```julia
using StatsBase

prob = rand(Float32, 3, 4)
prob ./= sum(prob)    # 归一化

# 1. 加权采样（放回）
samples = sample(1:length(prob), Weights(vec(prob)), 1024; replace=true)

# 2. 统计频数
freq = counts(samples, 1:length(prob))

# 3. 还原形状
new_hist = reshape(freq, size(prob))
```

### `sample` 函数

```julia
sample(population, weights, k; replace=true/false)
```

- `population` — 采样空间（这里是索引 `1:length(prob)`）
- `weights` — 权重，用 `Weights(w)` 包装
- `k` — 采样次数
- `replace=true` — 放回抽样

### `Weights` 包装器

`Weights(vec(prob))` 将普通向量包装为权重类型，`sample` 会自动归一化，不需要事先归一化。

### `counts` 函数

```julia
counts(samples, support) -> Vector{Int}
```

- `samples` — 采样结果向量
- `support` — 统计范围，如 `1:length(prob)`
- 返回值 — 与 support 等长的频数向量，`freq[k]` = 值 k 出现的次数

等价于手动：
```julia
freq = zeros(Int, length(prob))
for s in samples
    freq[s] += 1
end
```

### 注意事项

- `prob ./= sum(prob)` 后类型问题：如果 `prob` 是 `Int` 数组，`./=` 无法写回——应改用 `Float32.(hist) ./ sum(hist)`
- `counts` 和变量名冲突：同一行中 `counts = ...` 会导致右侧的 `counts` 被解析为新变量而非函数——**换变量名**或显式写 `StatsBase.counts`

## 要点

- `sample` + `Weights` + `counts` 是 Julia 加权采样的标准三步
- `Weights` 包装器自动处理归一化
- `counts(samples, support)` 统计频数
- 注意变量名不要与 `counts` 函数冲突
