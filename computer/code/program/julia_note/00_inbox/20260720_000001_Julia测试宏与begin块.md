# Julia `@testset` 宏与 `begin...end` 块

**日期**: 2026-07-20 20:30
**分类**: 编程/Julia
**标签**: #Julia #测试 #宏 #作用域

## 背景

查看 QMeasPost 项目的测试文件 `test/runtests.jl` 时，代码中大量使用了 `@testset` 和 `begin...end`，这两个是 Julia 测试和表达式组织的基础设施。

## 内容

### `@testset` 宏

来自 `using Test`，将一组 `@test` 断言嵌套在一个逻辑分组中。

**作用**：
1. **逻辑分组**：为测试块命名（如 `"utils"`、`"direct"`），方便阅读和定位
2. **局部作用域**：`@testset` 内的变量不会泄露到外部，每个 testset 是独立的 soft local scope
3. **报告汇总**：运行后输出按 testset 层级汇总的结果，一目了然看到哪个模块通过/失败

```julia
@testset "QMeasPost" begin
    @testset "utils" begin
        @test psi0 ≈ [1.0+0im, 0.0+0im]
    end
    @testset "direct" begin
        @test val ≈ 1.0
    end
end
```

### `begin...end` 块

将多条表达式合并成一个表达式块。

**要点**：
- **不引入 hard scope**：在 REPL 或脚本顶层，`begin...end` 里的变量仍是全局变量
- **主要用途**：将多行代码组织成一个表达式，传给宏或函数
- 在 `@testset "xxx" begin ... end` 中，`begin...end` 将内部所有测试作为一个整体传给宏

```julia
# 等价于：把多行代码打包成一个表达式块
x = begin
    a = 1
    b = 2
    a + b  # 返回值是最后一个表达式
end
# x = 3
```

## 要点

- `@testset` 创建局部作用域 + 分组 + 报告汇总
- `begin...end` 只是合并表达式（不创建新作用域），用来满足宏的参数需求
- 两者经常组合使用：`@testset "名称" begin ... test ... end`
