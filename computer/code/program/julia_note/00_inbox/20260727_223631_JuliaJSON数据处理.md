## JSON 模块核心用法

### 核心函数

| 函数 | 功能 |
|------|------|
| `JSON.parse(str)` | JSON 字符串 → Julia 数据结构（Dict/Array/Number/String） |
| `JSON.json(obj)` | Julia 对象 → JSON 字符串 |
| `JSON.parsefile(path)` | 读 JSON 文件直接解析为 Julia 数据结构 |
| `JSON.print(io, obj)` | 将 JSON 写入 IO 流 |

### 典型用法

```julia
using JSON

# 解析字符串
data = JSON.parse("{\"name\": \"qmeas\", \"qubits\": 4}")

# 序列化
println(JSON.json(data))

# 最常用：从文件读
result = JSON.parsefile("measurement_result.json")

# 写入文件
open("output.json", "w") do io
    JSON.print(io, dict)
end
```

`JSON.parsefile(path)` = `open(f -> JSON.parse(read(f, String)), path)`，即读文件 + 解析的便捷组合。

## Union{Nothing, T} 处理 JSON 可选字段

JSON 中某些字段可能存在也可能不存在，用 `Union{Nothing, T}` 类型声明优雅处理：

```julia
struct RandomMeasResult
    runner::String
    meas_mode::String
    trivial_params::Union{Nothing, Vector{Dict{String, Matrix{Float64}}}}
    trivial_count_group::Union{Nothing, Vector{Vector{Dict{String, Int}}}}
end
```

对应的解析函数检查 key 是否存在且不为 `null`：

```julia
function _opt_parse_params(raw, key)
    if haskey(raw, key) && !isnothing(raw[key])
        return [_parse_param_block(p) for p in raw[key]]
    end
    nothing
end
```

`Union{Nothing, T}` 是 Julia 中表示"可为空的值"的惯用方式，等价于其他语言的 `Optional<T>`。这种做法比用 `Dict{String, Any}` 更类型安全。

## 要点

- `JSON.parse` / `JSON.json` 是序列化反序列化的核心
- `JSON.parsefile` 是文件场景的便捷封装
- `Union{Nothing, T}` 表示可选字段，`haskey + isnothing` 双重校验
