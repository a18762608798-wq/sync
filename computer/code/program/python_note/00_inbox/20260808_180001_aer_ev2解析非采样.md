# Qiskit Aer EstimatorV2 是解析计算而非采样

**日期**: 2026-08-08
**分类**: 编程/Python
**标签**: #qiskit #qiskit_aer #estimator

## 背景

在 `qmeas` estimator 模块设计时，最初把 `shots` 放在公共 `EstimatorConfig` 中，后发现 Aer 路径完全不需要 shots。

## 内容

`qiskit_aer.primitives.EstimatorV2` 通过矩阵积态（MPS）或态矢量（statevector）方法**解析计算**期望值，不涉及采样统计：

```python
from qiskit_aer.primitives import EstimatorV2
estimator = EstimatorV2(options={"backend_options": {"method": "matrix_product_state"}})
job = estimator.run([(qc, observable)])
result = job.result()
evs = result[0].data.evs  # 精确值，无统计噪声
```

这意味着：
- `shots` 参数对 EstimatorV2 无意义——它不算概率分布，直接算 $\langle\psi|O|\psi\rangle$
- 与 `AerSimulator.run(shots=N)` 不同，后者做采样
- 只有 quarkstudio 真机 / 云模拟器才需要 shots

因此设计 `EstimatorConfig` 时应把 shots 放入 `QuarkEstimatorOptions`（Quark 专属），而非公共 config。

## 要点

- EstimatorV2 是解析的，无统计噪声，不需要 shots
- shots 只对采样式后端（真机、quark）有意义
- 设计公共配置时注意区分解析/采样路径的参数归属
