# Python 判零函数

**日期**: 2026-08-04 15:13
**分类**: 编程/Python
**标签**: #iszero #浮点数 #math #复数

## 背景

在 Julia 项目中常用 `iszero(x)` 判断数值是否为零，转到 Python 时寻找等价写法。

## 内容

Python 没有同名内置函数，常用等价方案：

| 写法 | 适用场景 | 说明 |
| ---- | ---- | ---- |
| `not x` | 任意对象真值判定 | `0`、`0.0`、`""`、`[]`、`False` 均为假；对 `0.0+0.0j` 也成立 |
| `x == 0` | 精确相等比较 | 浮点运算结果可能因舍入误差不成立 |
| `math.isclose(x, 0.0, abs_tol=...)` | 浮点容差判零 | 推荐用于浮点计算结果的判零 |
| `x.real == 0 and x.imag == 0` | 复数显式判零 | 明确检查实部虚部 |

复数注意：Python 中 `0j == 0` 为 `True`，所以 `x == 0` 可直接用于复数判零。

## 要点

- 无内置 `iszero`，按场景选 `not x` / `x == 0` / `math.isclose`。
- 浮点计算结果的判零应使用 `math.isclose` 加 `abs_tol`，避免精确比较失败。
- 复数可直接用 `x == 0`。
