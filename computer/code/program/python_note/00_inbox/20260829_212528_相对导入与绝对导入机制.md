# 相对导入 `.config` vs 绝对导入 `import config`

```python
# qmeas/random/runner.py (包内部文件)
from .config import RandomMeasConfig   # 相对导入: 从当前包 qmeas.random 找 config
# 等价于:
from qmeas.random.config import RandomMeasConfig  # 绝对导入: 写全名

# 下面这种写法在"包被安装后使用"的场景下会 ImportError:
import config  # 绝对导入: 只去 sys.path 顶层找 config
```

## 机制

Python 3 里所有不带点的 `import xxx` 都是**绝对导入**：只在 `sys.path` 顶层找名为 `xxx` 的模块。

- **直接 `python runner.py` 跑脚本**：脚本所在目录被放进 `sys.path`，同目录 `config.py` 能被找到，`import config` 成功。
- **`from qmeas.random import run_random` 当库用**：`sys.path` 顶层是 `src/`（site-packages 或 editable install），只有 `qmeas/` 目录，`config.py` 藏在 `qmeas/random/` 里，`import config` 找遍 sys.path 找不到 → ImportError。

`from .config import ...` 的 `.` 表示"从**当前模块所在的包**里解析"，不依赖 sys.path 顶层，两种场景都成立。

## 选择标准

| 场景 | 写法 | 原因 |
| ---- | ---- | ---- |
| 直接 python 跑脚本，同目录互导 | `import config` / `from config import X` | 目录在 sys.path 里 |
| pip 安装后当库 import（目录有 `__init__.py`） | `from .config import X` | 模块藏在包里，不在 sys.path 顶层 |

- 判断依据：**目录里有没有 `__init__.py` 且最终作为库使用**。
- 反向错误：普通脚本里写 `from .config import X` 会报 `ImportError: attempted relative import with no known parent package`（脚本没有"包"上下文）。
- `.config` 的点与隐藏文件无关，是"当前包"的缩写。

## 要点

- `import xxx` = 绝对导入，只查 `sys.path` 顶层；点号导入 = 相对当前包解析。
- 不是风格规范，是机制：选错会实际 ImportError。
- 脚本用不带点，包内部用带点；两者互斥。
- 相对导入好处：包改名/移动时内部导入不用改（不绑定顶层包名）。
