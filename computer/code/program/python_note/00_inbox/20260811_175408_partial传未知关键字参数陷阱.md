# functools.partial 传未知关键字参数的 TypeError 陷阱

**日期**: 2026-08-11 17:54
**分类**: 编程/Python
**标签**: #Python #functools #partial #TypeError #关键字参数

## 背景

在优化器封装中，用 `functools.partial` 根据布尔开关绑定不同的目标函数（普通/鲁棒），但因为两个函数签名不同，传入其中一个不接受的 `robust_options` 参数导致运行时 TypeError。

## 内容

### 问题：partial 不会自动忽略未知关键字

有人误以为传 `robust_options=None` 时，如果目标函数没有该参数，Python 会自动忽略。**这是错误的**：

```python
# objective 签名没有 robust_options 参数
def objective(t, end, pidx=1, step=1, order=1, history=None):
    ...

partial_objective = partial(objective, robust_options=None)  # 传了它不认识的参数名
partial_objective(t)  # TypeError: objective() got an unexpected keyword argument 'robust_options'
```

Python **不会自动忽略未知关键字参数**。`partial` 会把这些关键字无条件转交给目标函数，只要函数签名没有该参数就报 TypeError，与传的值是 None 还是 dict 无关——**是参数名的问题，不是值的问题**。

### 两种修法

**A. 拆分多个 partial（推荐，语义干净）**

```python
if robust:
    partial_objective = partial(robust_objective, ..., robust_options=robust_options)
else:
    partial_objective = partial(objective, ...)  # 不传 robust_options
```

**B. 给函数加一个被忽略的参数（改动小，但接口含混）**

```python
def objective(t, end, pidx=1, step=1, order=1, history=None, robust_options=None):
    # robust_options 在普通 objective 中不使用
    ...
```

## 要点

- partial 传的未知关键字会**无条件转交**目标函数，必然 TypeError
- 用三目 `A if cond else B` 选目标函数时，两个函数签名必须都能接受传入的所有关键字
- 报错源于"参数名"，与参数值是否为 None 无关
